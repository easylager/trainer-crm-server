# TASK-013: Тренер может самостоятельно добавлять города и арены

## Описание
Добавить тренеру возможность самостоятельно добавлять города и арены без участия администратора.

## Проблема
- Тренер зависит от администратора чтобы добавить новый город или арену
- Это замедляет работу и создает лишнюю бюрократию
- Новый город/арена может быть недоступны долго

## Решение
1. Добавить интерфейс для тренера чтобы добавить новый город
2. Добавить интерфейс для тренера чтобы добавить новую арену в своем городе
3. При добавлении новой арены — либо модерировать, либо сразу разрешить
4. При добавлении города — может быть требуется модерация или подтверждение
