# TASK-002: Организация использованных абонементов в списке

## Описание
Использованные абонементы нужно либо перемещать вниз списка выданных, либо показывать в отдельной категории «использованные».

## Проблема
- Список выданных абонементов смешивает активные и использованные
- Сложно отследить какие абонементы уже закончились

## Решение (вариант 1)
Добавить категоризацию с фильтром/раскрытием:
- Активные абонементы (свёрнуты по умолчанию открыты)
- Использованные абонементы (свёрнуты)

Решение (вариант 2)
Использованные абонементы автоматически скрываются или перемещаются вниз.
