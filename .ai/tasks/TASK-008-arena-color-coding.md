# TASK-008: Подсветка названий арен разными цветами

## Описание
Добавить визуальное различие для названий арен в карточке записи — каждой арене свой цвет.

## Проблема
- Сложно быстро понять в какой арене запись когда тренер работает в нескольких местах
- Названия арен просто текст без визуального выделения

## Решение
1. Назначить каждой арене фиксированный цвет (или из палитры)
2. Показывать название арены в карточке записи с соответствующим цветом фона или текста
3. Может быть добавить иконку или точку цвета рядом с названием

## Реализация (2026-09-03)
Не цвет — тема продукта («ЦВЕТ НАЗЫВАЕТ ТОЛЬКО ДЕЙСТВИЕ И СОСТОЯНИЕ», theme.css) уже закрыла эту
задачу в TASK-023 через приём «буква + плотность заливки», без цвета домена. Тот же приём
распространён на карточку записи в редакторе расписания (не в самом hub-списке бронирований —
там для этого нужен ещё и `arena_id` в SQL-запросе `_trainer_bookings_grouped_days_payload`,
которого сейчас нет; отдельный фаст-фолоу при необходимости):
- `static/webapp/schedule-editor-main.js`: `scheduleEditorArenaOrdinal`, `scheduleEditorArenaInitial`,
  `scheduleEditorArenaMonogramHtml` — стабильный порядковый номер площадки (по id) → буква + один
  из 3 паттернов заливки (сплошная/контур/штрих), без ограничения на число площадок (цикл по 3).
  Подключено в `scheduleEditorSlotVenueLine` (день-лист слотов), групповой meta-строке и
  `scheduleEditorArenaChipHtml` (чип точных слотов в редакторе шаблона).
- CSS: `.arena-mono` + `.arena-mono--p0/p1/p2` в `mini-app-components.css` (реюз `--app-cta-fill`).

Перепроверено на `master` (playwright, throwaway тренер с 2 аренами): день-лист
(`.slot-venue`) рендерит `<span class="arena-mono arena-mono--p0">М</span>` — монограмма
на месте у обеих точек использования.
