# TASK-011: Срок годности абонементов

## Описание
Добавить функцию срока годности абонементов — абонемент должен быть использован за определенное время.

## Проблема
- Абонементы могут лежать неиспользованными бесконечно
- Нет стимула для клиента использовать абонемент в разумный срок
- Тренер не знает когда абонемент «умрет»

## Решение
1. При создании абонемента указать срок годности (например 3 месяца)
2. Показывать дату истечения в списке абонементов
3. Когда абонемент истек, не позволять списывать занятия из него
4. Опционально: отправлять напоминание клиенту перед истечением
