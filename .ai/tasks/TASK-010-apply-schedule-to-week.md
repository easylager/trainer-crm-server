# TASK-010: Кнопка применить расписание на всю неделю

## Описание
При формировании расписания добавить кнопку «Применить ко всей неделе», когда расписание создано на один день.

## Проблема
- При создании расписания нужно повторять одно и то же для каждого дня недели
- Это долгая и скучная работа

## Решение
1. После создания расписания на один день показать кнопку «Применить ко всей неделе»
2. При клике скопировать это расписание на все остальные дни недели
3. Позволить выбрать какие дни применять (например только рабочие дни)
4. Показать превью того что произойдет перед применением
