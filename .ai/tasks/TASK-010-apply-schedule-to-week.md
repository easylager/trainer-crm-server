# TASK-010: Кнопка применить расписание на всю неделю

## Описание
При формировании расписания добавить кнопку «Применить ко всей неделе», когда расписание создано на один день.

## Проблема
- При создании расписания нужно повторять одно и то же для каждого дня недели
- Это долгая и скучная работа

## Решение
1. После создания расписания на один день показать кнопку «Применить ко всей неделе»
2. При клике скопировать это расписание на все остальные дни недели
3. Позволить выбрать какие дни применять (например только рабочие дни)
4. Показать превью того что произойдет перед применением

## Реализация (2026-09-03)
Чисто клиентская надстройка над уже сохранённым днём — новых бэкенд-эндпоинтов нет, задача
переиспользует захардененный `PUT /schedule/templates/day` (TASK-021/022/023: точные минуты,
arena_id, group_arena_id внутри одного `templateBody`), меняя в цикле только `day_of_week`.
- `static/webapp/schedule-editor.html`: модалка `#modalWeekApply` — превью, быстрые пресеты
  «Будни / Все дни / Снять всё», чипы дней недели, «Применить» / «Не сейчас».
- `static/webapp/schedule-editor-main.js`: после успешного сохранения дня шаблона (`editDone`)
  вызывается `openWeekApplySheet(state.editDay, templateBody)` вместо немедленного `showMain()`.
  Пустой день (0 слотов) сразу уходит в `showMain()`, диалог не показывается. Отмена не меняет
  ничего сверх уже сохранённого исходного дня — поведение полностью аддитивное к прежнему флоу.
  Дни применяются последовательно (`step()`, как в существующем `applyTemplateToWeeks`), с
  тостом об итоге, включая частичный отказ.
- CSS: `.week-apply-*` в `mini-app-schedule-editor.css`, реюз токенов темы и паттерна чипов
  `.schedule-grid-arena-chip`.
По умолчанию ни один день не выбран (осознанный выбор, а не «выбрано всё») — копирование дня
заменяет весь шаблон целевого дня, поэтому случайный клик «Применить» не должен стирать чужие
дни без явного намерения.

Перепроверено на `master` (playwright, throwaway тренер): сохранил Пн с 1 слотом → превью
«Скопировать расписание «Пн» (1 слот)...» → «Будни» выбрал 4 дня (Вт–Пт) → «Применить» →
модалка закрылась → в БД появились `trainer_schedule_templates` на day_of_week 0–4 с одним
и тем же временем — применилось на всю выбранную группу дней.
