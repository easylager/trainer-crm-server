# TASK-003: Информация об абонементе в карточке записи

## Описание
В карточке записи нужно видеть:
1. Оставшееся количество занятий по абонементу (не нужно проваливаться в карточку клиента)
2. Возможность перейти в абонемент из карточки записи (чтобы списать занятие и т.д.)
3. Возможность перейти в абонемент и из карточки клиента

## Проблема
- Нужно проваливаться в карточку клиента чтобы увидеть остаток абонемента
- Нет удобного способа списать занятие из карточки записи

## Решение
1. Добавить в строку «оплата» информацию об абонементе и остатке
2. Добавить ссылку/кнопку на абонемент в карточке записи
3. Сделать абонемент кликабельным как в карточке записи, так и в карточке клиента
