# TASK-009: Возможность добавить фото клиента

## Описание
Добавить клиентам возможность загрузить фото профиля в клиентском боте.

## Проблема
- У клиентов нет своего фото в системе
- Тренер не видит как выглядит клиент

## Решение
1. Добавить кнопку/поле для загрузки фото в профиле клиента
2. Сохранить фото на сервер (в uploads/clients/)
3. Показывать фото в карточке клиента в тренерском приложении
4. Показывать фото в профиле клиента в клиентском приложении
