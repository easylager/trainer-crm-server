# TASK-014: Выбор нескольких городов в онбординге

## Описание
Добавить возможность в онбординге выбрать несколько городов в которых тренер будет работать.

## Проблема
- Тренер может работать в разных городах но может выбрать только один
- Приходится проходить онбординг несколько раз или потом вручную добавлять города

## Решение
1. В шаге выбора города позволить выбрать несколько городов
2. Для каждого выбранного города показать ввод площадок
3. Создать расписание для каждого города
4. Сохранить все выбранные города и их расписания
