# TASK-007: История записей в клиентском боте

## Описание
Добавить в клиентском боте историю записей — список прошедших и будущих записей.

## Проблема
- Клиент не может посмотреть свою историю записей к тренеру
- Нет способа найти информацию о прошлой записи

## Решение
1. Создать раздел «История» в клиентском боте
2. Показать прошедшие записи (отсортированы по дате, новые в начале)
3. Показать будущие записи отдельно
4. Позволить кликнуть на запись чтобы увидеть детали
