# Task

## Objective

Для всех арен выбранного города выяснить, где публикуется расписание массового катания и в каком виде, и измерить распределение форматов. Это разведка перед стройкой: её результат определяет, сколько автоматики имеет смысл строить и какой потолок покрытия можно обещать бизнесу.

## Business Context

Катки свои страницы вести не будут — данные собираем мы. Но у нас в базе есть только название, адрес и координаты: ни одного сайта, ни одного сообщества. Пока неизвестно, какая доля катков вообще публикует расписание машиночитаемо, любая оценка сроков и покрытия конвейера — выдумка (`DESIGN-INGESTION-SYSTEM.md` §7).

Это самый дешёвый способ не построить дорогую машину под задачу, которой нет в предполагаемом виде.

## Scope

### In Scope
- По каждой активной арене выбранного города найти (руками, с помощью поиска и карт): официальный сайт, сообщество ВК/Telegram, карточку в справочнике организаций.
- Классифицировать, где именно лежит расписание: страница сайта · пост в сообществе · **картинка/афиша** · PDF · нигде (только по телефону/на месте).
- Классифицировать частоту обновления: постоянная сетка · еженедельный пост · хаотично.
- Зафиксировать наличие цен рядом с расписанием (бывает, что времена есть, а цены только на входе).
- Свести распределение: сколько арен в каждой категории, в процентах и в штуках.
- Оценить по итогам: доля арен, для которых автоматический сбор реалистичен; доля, требующая извлечения из картинок; доля, недостижимая без звонка.

### Out of Scope
- Написание кода сбора — TASK-061, TASK-065.
- Заполнение самих данных — TASK-063.
- Другие города — перепись делается по одному городу и повторяется при расширении.

Цены рядом с расписанием на той же странице: **Замок, led.by (соседний URL), Немига, Юность (цены без времён)**.

Частота: стабильная сетка (Замок) · еженедельная HTML (Чижовка, led.by, DiaMond) · выходной пост (Юность) · сезон окт–март (Немига).

### Потолок покрытия (AC-003)

Для **таба «Лёд» в Минске** цель — не 150 арен, а ~10–12 публичных катков.

| Как достигнуть уровня A | Доля публичных катков | Что это значит |
|---|---|---|
| Автоматически (HTML + LLM, без OCR) | **~5 из 12 сейчас, ~6–7 зимой** | Замок, Чижовка (времена), led.by, DiaMond (времена), Немига в сезон |
| Авто + вторая страница / соцсеть / браузерный снимок | **ещё 2–3** | Юность (VK/IG), ledlife (антибот), Чижовка/DiaMond цены |
| Только руками / звонок | **1–2** | Минск-Арена пока виджет мёртв; Раубичи пока «не проводятся» |
| Никогда как уровень A | **Манеж + школьные дворы** | Нет сеансов МК или только часы в PDF |

**Реалистичный потолок уровня A по Минску после конвейера: 7–9 катков из публичных ~12 (~60–75%), не 100%.** Этого достаточно для еженедельного продукта. Расширять на все CRM-арены Москвы как «пул сайтов» — нет: часть вообще не отдаёт лёд населению.

Первые 3 адаптера TASK-061 (по убыванию простоты): **ТЦ Замок → led.by → Чижовка**. Юность и ledlife — не в первую тройку (403 / соцсеть).
