# Task

## Objective

Заменить второй таб клиентского приложения («Тренеры») на таб «Лёд»: город в шапке, единый поиск, чипы намерения как линзы над одним набором арен, список арен с «живой строкой». Каталог тренеров сохраняется как одна из линз, а не как отдельная воронка.

## Business Context

Текущий вход во второй таб — анкета из четырёх обязательных шагов (город → услуга → площадка → результат), которая не отвечает на самый частый вопрос отрасли: где и когда сегодня лёд. Табов остаётся четыре, меняется смысл второго — это поглощение, а не переезд (`DESIGN-ARENAS-CLIENT-APP.md` §2).

## Design Reference

Экран прототипа **«Лёд — список»** (и **«Было: вход в каталог»** как исходное состояние для сравнения). Обязательно воспроизвести:
- шапка «📍 Минск · Изменить» и единый поиск «Каток, тренер или город»;
- чипы `⛸️ Покататься` / `🎯 Тренеры` / `👥 Группы`. Линза **«Покататься»**: в списке **только арены с ≥1 будущим слотом** `public_skate|open_ice` (решение 2026-09-05). Нет слотов → арены нет в этом списке; админ видит «результата нет» по последнему прогону (TASK-072). Линза «Тренеры» может показывать площадки без МК.
- переключатель «Список / Карта»;
- карточка арены: thumb-фото, имя с бейджем уровня A/B/C, «Район · расстояние · до 23:00», живая строка;
- подпись сортировки: «14 катков · сначала с актуальным расписанием».

## Scope

### In Scope
- Переименование и переназначение второго таба в `mini-app-client-shell.js` (список табов) с сохранением префетча и текущего поведения оболочки.
- Экран списка арен со всеми элементами прототипа; данные из TASK-051.
- Город определяется автоматически (сохранённая сессия → геолокация по кнопке → крупнейший) и меняется из шапки; экран выбора города перестаёт быть обязательным барьером, но остаётся доступным (с поиском, когда городов много).
- Единый поиск: арена / тренер / город.
- Существующий каталог тренеров (`screenSummary`/`screenTrainers` в `catalog.html`) сохраняется как линза «Тренеры» с фильтрами; ни одна его функция не теряется.
- Переход из карточки арены обратно в список сохраняет состояние (намерение, город, позицию).

### Out of Scope
- Карта — TASK-054 (переключатель ведёт на неё; до её готовности — существующая карта каталога).
- Карточка арены — TASK-052.
- Изменение табов «Главная», «Записи», «Ещё».

## Acceptance Criteria

### AC-001
Второй таб называется «Лёд» и открывает список арен; существующий путь к каталогу тренеров доступен максимум в один тап (чип «Тренеры»).
Requirement: CONFIRMED
Verification method: manual/exploratory + automated/unit (конфигурация табов)

### AC-002
Переключение чипов намерения меняет строку под названием и порядок арен, но не состав списка.
Requirement: CONFIRMED
Verification method: automated/integration (набор id совпадает при трёх намерениях) + manual

### AC-003
Арены отсортированы «сначала уровень A»; арена без расписания не притворяется полной, арена уровня C стоит ниже и не показывается в «Лёд сегодня».
Requirement: CONFIRMED
Verification method: manual/exploratory на реальных данных + automated/integration

### AC-004
Поиск по одной строке находит арену по названию и адресу, тренера по фамилии, город по названию; результаты сгруппированы по типу.
Requirement: CONFIRMED
Verification method: automated/integration + manual

### AC-005
Ни одна существующая функция каталога тренеров не потеряна: фильтры по услуге и аренам, группы с набором, карточка тренера, запись.
Requirement: CONFIRMED
Verification method: regression (существующие тесты каталога) + manual/exploratory по чек-листу функций

### AC-006
Клиент, ранее ходивший в «Тренеров», попадает к ним не более чем за один тап и видит понятную подсказку, куда делся каталог.
Requirement: INFERRED (риск сформулирован в дизайне; конкретная формулировка подсказки не утверждалась)
Verification method: manual/exploratory

## Edge Cases

### EDGE-001
Геолокация запрещена и сохранённого города нет — список должен показать крупнейший город и явную возможность сменить его, а не пустой экран.
Severity: MEDIUM
Status: OPEN

### EDGE-002
В городе нет ни одной арены уровня A — подпись «сначала с актуальным расписанием» становится ложной, нужен другой текст.
Severity: LOW
Status: OPEN

### EDGE-003
Клиент открыл таб по старому deep link на конкретный шаг каталога — ссылка должна остаться рабочей.
Severity: MEDIUM
Status: OPEN
