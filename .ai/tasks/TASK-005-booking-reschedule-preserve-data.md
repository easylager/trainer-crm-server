# TASK-005: Сохранение данных при переносе записи

## Описание
Когда переносишь запись, нужно заново выбирать тариф, площадку и т.д. Это лишнее действие — данные записи должны сохраниться.

## Проблема
- При переносе записи теряется контекст (тариф, площадка, услуга)
- Пользователь вынужден заново выбирать одно и то же

## Решение
Сохранить текущие параметры записи (тариф, площадка, услуга, клиент, длительность) и показать их как дефолтные при переносе. Пользователь может изменить только дату/время.
