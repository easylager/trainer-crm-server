# TASK-012: Сезонная арена (только в холодное время)

## Описание
Добавить кнопку/опцию «Сезонная арена» которая работает только в холодное время года.

## Проблема
- Некоторые арены работают только зимой или только летом
- Нет способа обозначить это в системе
- Тренер может случайно обслуживать сезонную арену в не-сезон

## Решение
1. При добавлении арены добавить опцию «Сезонная»
2. Если сезонная — выбрать месяцы работы (например декабрь-февраль)
3. Система автоматически скрывает/показывает эту арену в зависимости от текущего месяца
4. На расписание не позволять брать слоты в арене в не-сезон
