# TASK-006: Очистка слотов при удалении постоянной записи

## Описание
Когда убираешь постоянную запись, слоты остаются свободными и не удаляются. Нужно автоматически освобождать только те слоты, которые были заняты этой постоянной записью.

## Проблема
- После удаления постоянной записи в расписании остаются «зависшие» свободные слоты
- Нужно вручную очищать эти слоты

## Решение
При удалении постоянной записи:
1. Найти все слоты которые она занимала
2. Удалить их вместе с записью
3. Либо сделать запрос у пользователя: оставить слоты свободными или удалить
