# Minsk MK calibration gold (TASK-066)

Эталон точности извлечения. Сверяем **канон `ice_sessions`** (вид, локальное время, три цены), не HTML виджета.

Пилот: 7 минских катков со спекой и фикстурой (не 20–30 любых арен). Восьмой кандидат (Олимпик-арена) в набор не входит — нет `expected.json`.

Gold-файл каждой арены: `.ai/data/fixtures/<source_id>/expected.json` (`schema_version: canonical-slot-v1`). Слоты оттуда, не выдуманы.

## Метрики

На прогон (`python -m src.ingestion.calibration --check`):

- **recall** — доля эталонных сеансов, которые адаптер нашёл (полнота)
- **precision** — доля извлечённых сеансов, которые есть в эталоне (нет лишних)
- **price_accuracy** — среди совпавших: все три цены совпали
- **kind_accuracy** — среди совпавших: `public_skate` / `open_ice` совпал

Идентичность сеанса: `(local_date, starts_at_local, session_label)`. По каждому источнику и суммарно (микро).

TASK-062 забирает числа через `metrics_for_digest(report)` / CLI JSON. Этот модуль не правит текст еженедельной сводки.

## Когда обновлять эталон (EDGE-001)

Сверка на **том же сыром снимке** остаётся корректной, даже если живой сайт уже другой: ловим регресс селектора, не «свежесть кассы».

Обновлять gold, когда выполняется **хотя бы одно**:

1. Человек снял новый снимок после смены вёрстки / кассы / PNG прайса и **заново выверил** канонические слоты.
2. Горизонт снимка истёк (сутки для saleframe, неделя для HTML-сетки) и пилот больше не представляет текущую кассу — новый снимок + expected.json, старый можно оставить рядом, пока CI не переведён.
3. Квартальный просмотр пилота Минска (не чаще, если сайты не менялись).

Не обновлять gold, чтобы подогнать сломанный адаптер. Сначала чинить extract (или завести follow-up на адаптер). Новый каток — только со спекой `.ai/parsers/` и `expected.json` в каноне.

## Неоднозначные слоты (EDGE-002)

Сеанс с `"ambiguous": true` (или `"exclude_from_scoring": true`) **есть в эталоне**, но не входит в recall/precision/price/kind. Пример: «в выходные с 11:00, уточняйте» без сетки. В текущем пилоте таких сеансов нет — флаг проверен синтетическим тестом.

## Известные расхождения (не ослаблять gold)

- **led.by `expected.json`:** из gold убраны времена колонки «ОТРАБОТКА ХОККЕЙНОГО МАСТЕРСТВА» — это ОХМ, не МК (спека). Было 21 слот, стало 12.
- **DiaMond:** эталон 44 слота МК. Follow-up TASK-061 читает и `div.text-block-wrap-div` (в т.ч. два интервала в одной ячейке 10 сен). Gold не ослаблять.
- **Юность / ledlife:** нет адаптера и нет BY-egress. Терминал V1 = пустые слоты. Снимки 403/усечённого тела лежат рядом, чтобы не выдумывать сетку.
- **DiaMond `ceny.html`:** в репозитории нет (прайс — PNG по URL в expected). В калибровке сырьё слотов = `ledovaya-arena.html`.
