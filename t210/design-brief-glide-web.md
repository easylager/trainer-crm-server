# Бриф: Glide — единый веб-интерфейс каталога (дизайн v2)

Дата: 2026-10-07. Заказчик: владелец. Проверка: менеджер (Claude). Исполнитель: дизайн-агент.
Цель документа — один раз продумать продукт, маркетинг, UX, вирусность и ограничения, чтобы код потом не переделывать.

---

## 1. Что такое Glide

Бесплатный каталог мест для катания в Беларуси (затем Россия): катки (лёд), позже роллердромы, лыжероллерные трассы;
тренеры; магазины и сервис (прокат, заточка, экипировка). Цель — **«источник правды» о катании и инфраструктуре**: где
покататься сегодня, во сколько, сколько стоит, как добраться, с кем заниматься.

Деньги (позже) — с тренеров, школ и арен (подписки на CRM и продвижение), не с катающихся. Катающийся — всегда бесплатно.

## 2. Три правила системы (дизайн обязан их воплотить)

1. **Одна ссылка на каждую вещь.** У города, места, сеанса, тренера — одна ссылка `glideclub.by/…`. Её шарят, кладут в
   рекламу, в QR, на сайты катков. Она открывается везде (браузер, встроенный браузер Telegram/Instagram) с хорошим превью.
   Ссылки `t.me/…` наружу не показываем.
2. **Сайт — смотреть, Telegram — действовать.** Без входа: смотреть расписание, позвонить, маршрут, купить билет (на сайте
   катка). Через Telegram (кнопка на той же странице): записаться к тренеру, напомнить о сеансе, «позвать с собой»,
   абонемент. Логина на сайте нет — Telegram и есть аккаунт.
3. **Одна карточка, а не две.** Одна и та же страница показывается и в браузере, и внутри Telegram Mini App. Внутри Telegram
   она добавляет Telegram-кнопки («Назад», «Записаться», «Напомнить»), но остаётся той же страницей. Дизайн рисует
   **оба состояния каждой карточки**: «в браузере» и «внутри Telegram».

И принцип PDEC-019: **Glide — про катание, не только про лёд.** Общие экраны говорят нейтрально («Где покататься»,
«Куда катимся», «места», «сеансы»); «каток/лёд» — только внутри ледового вида. Вид активности — переключатель
«Лёд · Ролики · Лыжероллеры», показывается, когда видов больше одного.

## 3. Реальные данные (рисовать под них, не под идеал)

На 2026-10-07, прод:
- Беларусь: **37 ледовых мест** с карточкой, **13 магазинов**, 1 лыжероллерная трасса (Минск). 29 городов, Минск — 23 места
  (вместе с магазинами), большинство городов — **1 место**. Россия: Санкт-Петербург (8 катков с живым расписанием), Москва скрыта.
- Сеансы: живые с сайтов катков (~400 будущих), «обычная сетка катка» — расписание по типовой сетке (~210), «по фото
  афиши» (единицы). У каждого сеанса есть основание — его надо честно показывать.
- Режим места: обычный (расписание есть), **«только по телефону»** (7 мест — расписание не публикуют), **«сезон закрыт /
  ремонт»** (3, иногда с датой открытия). Расписание может быть **устаревшим** (не обновлялось N дней) — пометка.
- Фото есть **не у всех** мест (≈ половина) — нужен красивый вариант без фото.
- **Тренеров в публичном каталоге сейчас 4.** Блоки тренеров должны выглядеть хорошо при 0–3 карточках (честный пустой
  стейт + призыв «Вы тренер? Добавьте себя»).
- ОХМ (хоккей для любителей, вход по билету) — скоро у 4 катков Минска; отдельно от массового катания, фильтр
  «Хоккей (ОХМ)», условия: экипировка, шлем, лимит мест.
- Цены в BYN (в РФ — RUB), часы работы, телефон, сайт, соцсети, билеты (ссылка), прокат/заточка (флаги).

Не выдумывать цифры и названия: в макете — реальные (из этого раздела) или явные плейсхолдеры `[Каток]`, `[цена]`.

## 4. Аудитории и их задачи

| Кто | Пришёл откуда | Хочет за 10 секунд |
|---|---|---|
| Катающийся (взрослый, родитель с ребёнком, пара) | поиск «каток Минск расписание», ссылка друга, сторис | где и во сколько сегодня/в выходные, цена, как добраться |
| Хоккеист-любитель | чат, ссылка | ОХМ: когда, сколько, места есть? |
| Друг, которого позвали | ссылка «иду в 18:00 на Чижовку» | понять куда/когда, нажать «я тоже» |
| Ученик тренера | ссылка тренера | кто тренер, где занимается, записаться |
| Тренер (платит) | личная продажа, `/trainers` | «меня найдут здесь», моя страница выглядит профессионально |
| Каток (партнёр) | наш звонок, QR | «наше расписание здесь точное», ссылка для своих соцсетей |

## 5. Экраны (что нарисовать)

Mobile-first (390 px) **и** десктоп (1280 px) для каждого. Для карточек — состояния «браузер» и «внутри Telegram».

1. **Главная** `glideclub.by/` — вход в три раздела.
   - Шапка: «Где покататься сегодня», живой счётчик («Сегодня N сеансов в M городах» — считается сервером),
     большая кнопка города посетителя («Минск — 21 сеанс сегодня →», город по IP, иначе Минск), поиск «город или место»,
     переключатель вида активности.
   - **Карта Беларуси** с точками городов (SVG, рисуется сервером; размер точки — число мест; подпись — сеансы сегодня;
     тап → город). Владелец выбрал концепцию с картой.
   - Ближайшие сеансы в городе посетителя (с днём: сегодня/завтра/дата; только своя страна).
   - Города: крупные карточками, остальные сгруппированы по областям.
   - Тренеры (при малом числе — честный стейт + «Вы тренер?»), Магазины и сервис.
   - Россия отдельным блоком. Ссылка «Тренерам» (B2B-лендинг `/trainers`).
2. **Город** `/минск` (или `/c/минск`) — карта города с точками мест, фильтры (вид активности, «сегодня / выходные»,
   «магазины / залы», ОХМ), список мест с ближайшим сеансом, режимом и ценой; пагинация; «Лёд сегодня» раздел.
3. **Место** `/p/минск/чижовка` — фото или вариант без фото, адрес, «сейчас открыто / закрыто», расписание по дням
   (основание сеанса: живое / обычная сетка / по фото; устаревшее — пометка), цены, прокат/заточка, телефон, маршрут,
   билеты, тренеры этого места, ОХМ отдельным блоком, «Сообщить об ошибке», «Поделиться». Режимы «только по телефону» и
   «сезон закрыт» — свои варианты экрана.
4. **Сеанс / «позвать с собой»** — то же место с выделенным сеансом и плашкой «[Имя] идёт в 18:00 — пойдёшь?»; кнопки
   «Я тоже» (→ Telegram: напоминание обоим), «Маршрут», «Поделиться дальше».
5. **Тренер** `/t/минск/[имя]` — фото, специализация (фигурное/хоккей/взрослые/дети), где работает (ссылки на места), цены,
   отзывы, «Записаться» (→ Telegram), «Поделиться». Тренер шарит её ученикам — должна выглядеть как «визитка, которой
   гордятся».
6. **Превью ссылок** (OG-картинки 1200×630) и **сторис** 1080×1920: место, сеанс-приглашение, «лёд сегодня в городе»,
   тренер. Это то, что люди видят в Telegram/WhatsApp/Instagram до клика — главный носитель вирусности.
7. **Мост в Telegram** — что видит человек, нажавший «Напомнить / Я тоже / Записаться» без Telegram на устройстве
   (объяснение + ссылка на установку + «продолжить без»).
8. **QR-плакат для катка** (A4): «Наше расписание — на Glide» + QR на страницу места.
9. Пустые/ошибочные состояния: город без сеансов сегодня, место без фото, 0 тренеров, 404 места, устаревшее расписание.

## 6. Вирусные петли (дизайн каждой — явно)

1. **Тренер → ученики**: страница тренера + превью + «поделиться» в 1 тап; на странице тренера — его места и каталог.
2. **«Позвать с собой»**: шаринг сеанса с именем и временем → «Я тоже» → напоминание обоим → после катания
   «как прошло? позвать ещё».
3. **Каток → посетители**: QR и ссылка для соцсетей арены.
4. **«Лёд сегодня» сторис**: ежедневная картинка города для Instagram.
Каждая кнопка «Поделиться» отдаёт **одну и ту же** ссылку `glideclub.by/…` + текст + картинку-превью.

## 7. Маркетинговые входы

- Реклама/сторис для катающихся → страница города с меткой `?src=insta|tiktok|vk|qr` (без установки, сразу польза),
  на странице — «Напоминать о сеансах в Telegram».
- Поиск: страницы городов/мест/«лёд сегодня» — главные SEO-входы; title и H1 конкретны для льда, общие — нейтральны.
- Тренеры — личные продажи, страница `/trainers` (существует, не перерисовывать).

## 8. Ограничения (нарушение = переделка)

- Страницы рендерятся **сервером** и работают **без JavaScript** (поиск — обычная форма; JS только улучшает).
- Быстро на слабом телефоне и медленной сети: без тяжёлых библиотек и внешних карт (карта — свой SVG), шрифт один
  (Golos Text), картинки с размерами. Бюджет: страница ≤ ~200 KB gzip.
- Работает во встроенных браузерах Telegram и Instagram; внутри Telegram Mini App — тема Telegram (светлая/тёмная),
  кнопка «Назад» Telegram, без собственного «назад».
- Доступность: контраст 4.5:1, цели касания ≥ 44 px, настоящие ссылки/кнопки, подписи у полей.
- Палитра Glide (текущие страницы): фон #f4f6f7, поверхность #ffffff, текст #0d1b26, вторичный #5d7285, линия #e1e8ec,
  акцент #0f8f8a (текст-акцент #0b6f6b), заливка акцента #e3f4f3. Можно развить, но не менять бренд.
- Язык: русский, по-человечески, без канцелярита; никаких выдуманных фактов.
- Компонентно: одни и те же блоки (карточка места, строка сеанса, карточка тренера, плашка режима, кнопка Telegram)
  переиспользуются на всех экранах — это то, что потом станет общим кодом.

## 9. Что сдать

- Папка `docs/design/glide-v2/` в своей ветке: по одному **статичному HTML-файлу на экран** (inline CSS, без внешних
  библиотек; Google Fonts допустим), мобильная и десктопная версия (media queries) и состояние «в Telegram»
  (переключатель класса на `<body>` или отдельный файл). `index.html` со ссылками на все экраны.
- `docs/design/glide-v2/README.md`: решения и почему; список компонентов (имя, где используется, состояния);
  карта переходов (какая кнопка куда ведёт: сайт → Telegram → обратно); тексты кнопок; какие события учёта
  (просмотр, звонок, маршрут, билеты, «я тоже», «поделиться») на каких кнопках; открытые вопросы владельцу.
- OG/сторис — как HTML-артборды нужного размера.

## 10. Как будет проверяться

Менеджер проверяет по разделам 2, 3, 5, 6, 8: все экраны и состояния есть; три правила соблюдены (нигде нет «вот сайт /
вот бот», одна ссылка, состояние «в Telegram» нарисовано); реальные стейты данных (без фото, по телефону, сезон закрыт,
устарело, 0 тренеров); вирусные петли до конца; без JS работает; доступность; нейтральность по PDEC-019.

## 11. Дополнение (2026-10-07, по итогам концепт-исследования) — обязательно учесть

Центр продукта — **надёжная страница катка и города + подписка в Telegram**, а не лента «рядом» (в 28 из 29 городов одно место).

1. **«Следить за катком»** (кнопка на странице места → Telegram): уведомление, если сеансы на ближайшие дни изменились
   (пропали / добавились — видим при каждом обновлении расписания), и «каток снова открыт» для закрытых
   (`season_closed`, напр. Жодино). Нарисовать: кнопку, состояние «вы следите», пример сообщения в Telegram.
2. **Лента «сегодня рядом»** — только где мест много (Минск, Санкт-Петербург). В малых городах главная/город ведут сразу
   на страницу катка.
3. **Сеансы «по типовой сетке»** — мягко: «обычно в это время», без «сейчас идёт», визуально тише живых. Живые — «с сайта
   катка, обновлено N ч назад».
4. **«Сейчас идёт · осталось 25 мин»** для живого сеанса; **полная цена выхода**: билет + прокат (если есть).
5. **Пустое состояние**: «Сегодня здесь сеансов нет. Ближайший — завтра в 18:00» или соседний город, если близко.
6. **«Позвонить»** с подсказкой, что спросить («Сеанс в 19:00 будет?»), для режима «только по телефону».
7. **«Первый раз на коньках»** — одна статичная страница-гид (что надеть, прокат, бортик), ссылка с главной и карточек.
8. Подпись в подвале: «Сделано теми, кто сам катается. Нашли ошибку — напишите».
Не делать: рейтинги и звёзды, отзывы, логин, своя оплата, приложение в сторах, «первый сеанс после заливки», прогноз
погоды для уличных, паспортные поля, которых нет в данных (размеры проката, тёплая трибуна).
Метрики, под которые проектируем: поисковый трафик на страницы катков и городов; подписки «следить за катком» и их
удержание через 2–4 недели; жалобы «приехал, а сеанса нет».

## 12. Не только «сегодня» и одна система с Mini App (владелец, 2026-10-07)

- Выбор времени на главной, в городе и на месте: «Сегодня · Завтра · В выходные · День…» — те же ключи и слова, что в Mini App
  (`ice-tab-model.js`: today/evening, tomorrow, weekend, day). С пятницы 15:00 по умолчанию «В выходные». Внутри Mini App уже
  есть разнобой («В выходные» / «Выходные») — выровнять на одно слово.
- Одна система вместо двух: (1) общие дизайн-токены (цвета, шрифт, радиусы, отступы) одним CSS-файлом для `static/share` и
  `static/webapp`; (2) общий словарь подписей (дни, «обычно», «с сайта катка», режимы места, ОХМ) одним модулем для Python и JS;
  (3) карточки места/города/тренера — один серверный шаблон: сайт отдаёт его как есть, Mini App открывает ту же страницу и
  добавляет Telegram-кнопки (PDEC-020, правило 3). Новые экраны каталога проектируются один раз — как страница сайта с
  состоянием «в Telegram».
