## Сделать (сверху вниз, как в макете)
1. **Шапка**: «Glide» (ссылка на `/`), иконка поиска (якорь к форме поиска). Вне Telegram — наша шапка; внутри Telegram — скрыта (класс `tg`, см. TASK-212).
2. **Дата-строка** («Пятница, 9 октября») — Europe/Minsk.
3. **H1 «Где покататься»** + **переключатель времени** «Сегодня · Завтра · В выходные · День…» (ключи `when.*` из TASK-209). Реализация: ссылки `?when=today|tomorrow|weekend|day&d=YYYY-MM-DD` (работают без JS); «День…» без JS ведёт на `?when=day` со списком ближайших 7 дат ссылками. **По умолчанию:** Пн–Пт до 15:00 — «Сегодня»; Пт с 15:00, Сб, Вс — «В выходные» (ближайшие Сб+Вс; в Вс после 18:00 — следующие). Варианты с `?when=` — `noindex, follow`, canonical на `/`.
4. **Счётчик**: «Сегодня в Беларуси N сеансов в M городах» / «В эти выходные N сеансов в M городах» — считается сервером одним сгруппированным запросом с общим предикатом `ICE_CITY_DAY_SESSION_WHERE_SQL` (как сейчас для «сегодня»), только BY.
5. **Кнопка города** (`#0f8f8a`): «Минск — N сеансов сегодня / в выходные →», подпись «Ваш город · сменить». Город: cookie `glide_city` (ставится при заходе на `/c/{city}` или `/p/{city}/…`, 180 дней, только slug), иначе Минск. Геолокацию по IP не делаем (ip_geo знает только страну). «сменить» — якорь к списку городов.
6. **Чипы вида**: «Лёд · Хоккей (ОХМ) · Лыжероллеры · Первый раз». Показывать «Хоккей (ОХМ)» только если в стране есть будущие `hockey_practice` (до TASK-201-B — ведёт на `/c/{city}?kind=ohm` либо скрыт, если страница не готова); «Лыжероллеры» — если есть видимые места этого вида (сейчас arena 12, `venue_type=other` — см. Q-001); «Первый раз» → `/first-time` (TASK-215). Активный — «Лёд».
7. **Блок ближайших сеансов** — только для городов, где ≥5 мест с сеансами (сейчас Минск, СПб); для остальных городов кнопка города ведёт прямо на страницу места, если место одно. Заголовок «Ближайшие в {город}» (или «{город}, сб и вс» для выходных), до 3 карточек, «Весь день →»/«Все →» на `/ice/{city}/today` или `/c/{city}?when=weekend`. Карточка: время крупно, под ним «через N мин» (если < 2 ч, живой сеанс) или день; название места; «с прокатом X BYN · с сайта катка». Сеанс `projected` — **пунктирная** рамка, фон `#f9fbfb`, подпись «обычно» и «по обычной сетке катка — лучше уточнить», никогда «через N мин». Только своя страна.
8. **Карта Беларуси**: SVG рисуется сервером: контур страны (упрощённый полигон — можно взять из макета, пересчитать в проекцию), точки городов по координатам (среднее координат видимых мест города), радиус ~ число мест (мин 5, макс 10), у Минска ореол. Подписи — 6 областных центров. Каждая точка — `<a href="/c/{city}">` с `<title>`. Без внешних библиотек и тайлов.
9. **Города**: Минск — тёмная карточка («9 катков · 21 сеанс сегодня» — считать катки по `venue_type` ice, отдельно не смешивать с магазинами); затем областные центры по убыванию сеансов, затем мест; далее `<details>` «Все города по областям · N» — группы по областям. Справочник «город → область» — константа в коде для всех 29+ городов BY (тест: каждый публичный BY-город имеет область). Россия — отдельной строкой внизу («Санкт-Петербург»).
10. **Тренеры в {город}**: до 3 карточек (фото/инициалы, имя, специализация, место) по правилу видимости каталога тренеров; при 0 — блока нет, но всегда есть плашка «Вы тренер? Ученики уже ищут лёд здесь · Добавить себя →» на `/trainers`. Ссылки карточек — на страницу тренера (TASK-206), до неё — в Telegram через open-telegram.
11. **Магазины и сервис**: три плитки «Прокат · Заточка · Экипировка» → `/c/{city}?type=shop` (с фильтром услуги, если есть данные), подпись «13 магазинов в Минске» — реальное число.
12. **«Первый раз на коньках?»** — карточка-ссылка на `/first-time`.
13. **Подвал**: «Сделано теми, кто сам катается. Расписание — с сайтов катков.» + «Нашли ошибку?» (→ Telegram-бот, TASK-194; до него — open-telegram с `startapp=report`), «Санкт-Петербург», «Тренерам».
14. Десктоп (≥ 1024 px): двухколоночная шапка с картой справа как в `Main.html`; остальное — сетками.
15. SEO: title «Где покататься в Беларуси — катки и расписание массовых катаний | Glide», description нейтральная (PDEC-019), JSON-LD WebSite + ItemList городов (как в 191-A).
