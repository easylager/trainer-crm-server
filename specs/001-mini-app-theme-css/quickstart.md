# Quickstart: добавить theme к странице

1. Убедись, что `static/webapp/theme.css` существует в ветке (после первого PR фичи).
2. В `<head>` страницы добавь **до** встроенного `<style>`:
   ```html
   <link rel="stylesheet" href="theme.css" />
   ```
3. Замени дублирующий блок `:root { --tg-theme-... }` и повторяющиеся hex на использование `var(--app-*)` в классах (см. `contracts/theme-tokens.md`).
4. Удали `!important` там, где конфликт решён токенами (по возможности).
5. Проверь в Telegram WebApp: светлая и тёмная тема, основной сценарий страницы.

Пилотные страницы для эталона: `catalog.html`, `book.html` (после миграции).
