# Пригласить клиента из лички

Кратко для тренера и для администратора.

## Тренер (2 действия)

1. В меню команд бота выберите **«Пригласить клиента»** (команда `/invite`) или откройте **«Помощь»** (`/guide`) и нажмите **«Пригласить клиента»**.
2. Бот пришлёт короткую подсказку и **следующим сообщением** — готовый текст со ссылками. Его можно **целиком переслать** клиенту в Direct или скопировать.

Ссылка вида `https://t.me/<клиентский_бот>?start=client_<город>_<услуга>_<тренер>` совпадает с обработкой в клиентском боте (`client_handlers`): клиент попадает в бота с уже выбранным вами в профиле городом, услугой и вашим профилем.

## Администратор (продакшен)

Чтобы ссылки были валидны:

| Переменная | Назначение |
|------------|------------|
| `CLIENT_BOT_USERNAME` | Имя клиентского бота **без** `@` (как в `t.me/...`). Иначе бот сообщит тренеру, что ссылку собрать нельзя. |
| `WEBAPP_BASE_URL` | Базовый URL API **с HTTPS**, например `https://api.yourdomain.com`. Тогда во вторую ссылку попадёт `.../webapp/catalog`. При `http://localhost` ссылка на каталог в текст для клиента **не добавляется** — остаётся только deep link в бота и подсказка про меню «Тренеры и запись». |

Код сборки ссылок: `src/application/trainer_invite_links.py`. Тексты: `src/bot/messages.py` (префикс `TRAINER_INVITE_`).
