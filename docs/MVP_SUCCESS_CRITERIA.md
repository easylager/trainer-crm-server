# Критерии успеха MVP (цифры и периоды)

Согласованный набор **допущений** и **измеримых порогов** для оценки MVP. Цифры можно пересчитать под фактический запуск (один город / несколько, пилот / платный набор).

---

## Допущения


| Допущение               | Значение                                                                                                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| География первого MVP   | **Минск + пригород** (один пул спроса/предложения)                                                                                                                        |
| Канал                   | **Telegram** как основной; сайт — онбординг тренера и публичный каталог                                                                                                   |
| Модель                  | **B2B2C**: без достаточного числа активных тренеров клиентский опыт «пустой»                                                                                              |
| Старт                   | **пилот 4–8 недель** (ручной набор, «белый список»), затем открытый или полуоткрытый приём                                                                                |
| «Активный тренер»       | статус **active** в системе **и** за последние **28 дней**: ≥**1** свободный слот **или** ≥**1** завершённая/подтверждённая бронь (зафиксировать одну формулу в продукте) |
| «Активный клиент (MAU)» | за **28 дней** открыл мини-апп/бот **и** сделал **≥1** значимое действие (запись, заявка, отмена, отклик на заявку)                                                       |


---

## Иерархия метрик

1. **Ликвидность** — клиент находит слот / получает отклик; тренер получает бронь.
2. **Повтор** — не разовый эксперимент.
3. **Качество** — не разваливается из‑за отмен и тишины.
4. **Экономика B2B** (когда включена оплата) — тренеры **платят и остаются**.



## Период A — Пилот (недели 1–8 после первого живого тренера)

**Цель:** доказать, что **сквозной цикл** работает без ручного сопровождения каждой записи.


| Метрика                                                                            | Порог «успех пилота»                              | Обоснование                                     |
| ---------------------------------------------------------------------------------- | ------------------------------------------------- | ----------------------------------------------- |
| Тренеры в пилоте                                                                   | **15–25** с полным профилем (услуги, фото, слоты) | Достаточно для ощущения каталога в одном городе |
| Доля пилотных тренеров с **≥1 подтверждённой/завершённой** бронью                  | **≥60%** за 8 недель                              | Иначе проблема в спросе, цене, UX или слотах    |
| Медиана **дней до первой** такой брони у тренера                                   | **≤21 день**                                      | Иначе онбординг/активация слабые                |
| Клиентские **завершённые** сессии (или подтверждённые, если завершение редко жмут) | **≥80** за 8 недель совокупно                     | Порядок величины для вывода «это не демо»       |
| **Открытые заявки** («не нашёл тренера»): доля с **≥1 откликом** за 72 ч           | **≥40%**                                          | Матчинг живой                                   |
| Критические инциденты                                                              | **0** необработанных блокеров >**48 ч**           | Оплата, бот, запись                             |


**Итог пилота (go / no-go к масштабированию набора):** ≥**60%** тренеров с реальной бронью **и** ≥**80** клиентских «успешных» касаний к расписанию за 8 недель.

---

## Период B — MVP на трафике (месяцы 3–6 после конца пилота)

**Цель:** выйти от «друзей основателя» к **устойчивому мини-рынку** в одном городе.


| Метрика                                   | Порог на **конец 6-го месяца**                | Обоснование                                     |
| ----------------------------------------- | --------------------------------------------- | ----------------------------------------------- |
| Активные тренеры (28d)                    | **40–70**                                     | Минимум для ощущения каталога в Минске          |
| Новые брони (созданные)                   | **≥400 / месяц** к концу 6-го месяца          | Скромно, но измеримо                            |
| Коэффициент **повтора** клиента           | **≥25%** клиентов с **≥2** бронями за 90 дней | Продукт не только «раз попробовал»              |
| **Отмена** тренером (после подтверждения) | **≤12%** от подтверждённых                    | Выше — бьёт по доверию (можно ужесточить до 8%) |
| Средняя оценка после занятия              | **≥4.3** при **N≥30** оценок/квартал          | При малом N — качественный разбор               |


### Экономика (если подписка тренера уже продаётся)


| Метрика                            | Порог                    |
| ---------------------------------- | ------------------------ |
| Платящие активные тренеры          | **≥25** к месяцу 6       |
| Месячный **churn** платящих        | **≤8%** (скользящий 28d) |
| **Trial → paid** (если есть триал) | **≥35%**                 |


Если подписки ещё нет: **≥30%** активных тренеров согласились бы платить **X BYN/мес** по опросу (**N≥20**).

## Период C — «MVP доказан» (месяц 12)


| Метрика                                          | Порог                                                         |
| ------------------------------------------------ | ------------------------------------------------------------- |
| Активные тренеры (28d)                           | **80–120** (один город) или **50+** в **каждом** из 2 городов |
| Брони                                            | **≥1000 / месяц** стабильно **2 месяца подряд**               |
| Доля тренеров с **≥4** активными неделями подряд | **≥50%** от активных                                          |
| NPS тренеров (опрос)                             | **≥+20** (цель **+30**)                                       |


---

## Приземление под продукт (чеклист)

1. Зафиксировать **одно** определение «активный тренер» и «успешная бронь».
2. Включить в дашборд **еженедельно**: активные тренеры, новые брони, отмены, отклики на заявки, дни до первой брони.
3. При запуске **не в Минске** или **узкой нише** — делить абсолютные пороги на **2–3** или пересчитывать от целевого числа тренеров.
