# Ссылка из сайта в клиентский бот

Если пользователь на сайте уже выбрал город, услугу и тренера, можно отправить его в бота по ссылке — сессия подставится автоматически, он сразу увидит экран «Выбран: …» с кнопками **Записаться** и **Выбрать другого тренера**.

## Формат ссылки

```
https://t.me/<CLIENT_BOT_USERNAME>?start=client_<city_id>_<service_id>_<trainer_id>
```

Пример: при выборе город 1, услуга 2, тренер 5:

```
https://t.me/client_crm_local_bot?start=client_1_1_4
```

- `CLIENT_BOT_USERNAME` — username клиентского бота без `@`.
- `city_id`, `service_id`, `trainer_id` — целые положительные ID из вашей БД/API (те же, что в `client_sessions` и в API тренеров).

Параметр `start` ограничен 64 байтами; формат `client_C_S_T` укладывается с запасом.

## Поведение в боте

1. Пользователь переходит по ссылке и открывает бота.
2. Бот получает `/start client_1_2_5`, парсит payload.
3. В сессию (по `telegram_id`) записываются `city_id`, `service_id`, `selected_trainer_id`.
4. Отправляется сообщение: «Выбран: &lt;имя тренера&gt;» и кнопки **Записаться** / **Выбрать другого тренера**.

Если payload невалидный или отсутствует — показывается обычный приветственный экран с кнопкой «Выбор тренера».
