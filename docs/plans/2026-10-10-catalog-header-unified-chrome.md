# Шапка каталога — единый визуальный язык (без смены логики)

**Date:** 2026-10-10  
**Статус:** принято (фаза 2 — разметка)  
**Макет-референс:** поведение как сейчас; один компонент `ice-chips` + `ice-chip` во всех режимах.

## Решение

Логика режимов, API, видимость блоков и выпадающие меню **не меняются**. Меняется только то, как выглядит второй ряд фильтров на всех вкладках.

## Один язык — `ice-chip`

| Режим | Было | Стало |
|---|---|---|
| **Места** (тип) | `ice-seg--quiet` | контейнер **`ice-chips`**, кнопки **`ice-chip`** |
| **Места** (место/когда) | прямоугольные `ice-tool` | **пилюли** как чипы |
| **Тренеры** | мелкие `ice-chips--svc` | те же размеры чипа, что у мест и магазинов |
| **Магазины** | фиолетовый outline + kickers «Что нужно» | **те же чипы**, что у тренеров; kickers скрыты |
| **Магазины** (время) | `ice-shop-toggle` другой формы | **чип** + зелёная точка только как иконка «живое» |

Верхний овал разделов (`ice-seg` в `ice-intent-row`) не трогаем — это один паттерн на всех вкладках.

Фильтры собраны в **`#iceFilterBand`**: между рядами всегда `7px`, без отдельных отступов у блока магазинов.

## Не делаем

- Не сливаем магазины/тренеров/места в одну ленту.
- Не заменяем выпадающие «Все места» / «Когда» на ряд из четырёх пресетов (см. `catalog-search-header.md`).
- Не трогаем `ice-board` и список.

## Проверка руками

1. Минск → Покататься → типы места выглядят как чипы, не underline.
2. Магазины → «Заточка / Розница» — активный чип бирюзовая заливка, как «С нуля» у тренеров.
3. Магазины → нет заголовков «Что нужно» / «Когда удобно» (подписи остаются в `aria-label` у групп).
4. Места с длинным хвостом типов → «Все места ▾» — пилюля как чип.
