# ОХМ в каталоге: согласованный показ на сайте и в Mini App

Дата: 2026-10-09  
Статус: дизайн согласован с владельцем (вариант discovery + слоты как у МК)  
Задача: TASK-201 (201-B показ; 201-A данные уже в проде)  
Макет-база: `.ai/epics/catalog-standalone/design-v2/` — **блок ОХМ на Place.html устарел** (сводка без слотов); целевой UI — как «Массовое катание».

## Проблема

ОХМ (`hockey_practice`) уже пишется парсерами четырёх минских катков, но публичные поверхности его не показывают (или показывают только сводкой без «позвать»). Хоккеист-любитель не находит «где сегодня ОХМ» тем же путём, что катающийся находит массовое катание.

## Принятые решения

| Решение | Выбор | Отклонено |
|---|---|---|
| Продукт | Только ОХМ (не ОФМ) | ОФМ |
| Discovery | Чип **«Хоккей (ОХМ)»** → город с фильтром → место | Только блок на карточке; отдельный `/ohm` |
| Карточка места | **Те же слоты, что у МК** (день · время · цена · «позвать») + условия под списком | Сводка «Сб 08:45, …» без кнопок; гибрид |
| Катки v1 | led.by (ЛД МО), DiaMond, Чижовка, СДЮШОР/ledlife | Кобрин, Островец в этом заходе |
| СДЮШОР | Ручной ingest с машины владельца (local BY egress), без VPS | Покупка BY VPS |
| Запись/оплата | Не через нас | Билеты у нас |

## Словарь (сайт = Mini App)

| Ключ / место | Текст |
|---|---|
| Чип, фильтр города, режим таба | **Хоккей (ОХМ)** |
| Заголовок секции на месте | **Хоккей для любителей (ОХМ)** (`kind.hockey_practice`) |
| Массовое / «Лёд» / тизеры | ОХМ **не** попадает |

Условия (если есть в данных катка): экипировка, шлем детям, лимит мест, «билеты в кассе». Нет данных — строку не рисуем.

## Путь пользователя

```
Главная сайта / таб «Лёд» в Mini App
  → чип «Хоккей (ОХМ)»
    → /c/{city}?kind=ohm  (или эквивалент в Mini App)
      → только катки с будущим hockey_practice
        → /p/{city}/{slug}  (карточка арены)
          → секция ОХМ: вкладки дней + строки сеансов + «позвать»
```

Прямой заход на каток без чипа: секция ОХМ всё равно видна, если есть будущие сеансы.

## Поверхности

### Главная сайта

- Чип «Хоккей (ОХМ)» только если в стране есть будущий `hockey_practice`.
- Ведёт на `/c/{city}?kind=ohm` (город из cookie / Минск).
- Пока сеансов 0 — чип скрыт.

### Город `?kind=ohm`

- Список только катков с будущим ОХМ.
- В карточке: ближайший слот, цена, подпись арены при необходимости.
- Счётчики «N сеансов массового» с ОХМ не смешиваются.
- Активный чип — «Хоккей (ОХМ)».

### Место `/p/…` (и карточка арены в Mini App)

Две независимые секции:

1. **Массовое катание** — как сейчас (только `public_skate` / `open_ice`).
2. **Хоккей для любителей (ОХМ)** — тот же паттерн:
   - справа свежесть / «с сайта катка» (как у МК);
   - вкладки дней на 7 дней, только дни с ОХМ или с нулём как у МК;
   - строка сеанса: время крупно + «до HH:MM»; цена (обычно одна взрослая для ОХМ); подпись арены (БА/МА → «Большая/Малая арена»);
   - справа «позвать» → `/p/…?s={session_id}&i=1` (тот же invite, что у МК, TASK-214);
   - под списком — условия посещения одной-двумя строками.

Секция ОХМ скрыта, если будущих `hockey_practice` нет. ОХМ никогда не в строках МК.

### Mini App «Лёд»

- Тот же чип и тот же режим списка, что на сайте.
- Не путать с фильтром тренеров «Хоккей» (дисциплина тренера ≠ ОХМ).
- Карточка арены: та же секция слотов ОХМ.

### Лёд сегодня / тизеры / hub

Без изменений для МК. ОХМ только через фильтр или секцию места.

## Согласованность сайта и приложения

- Один словарь `copy_ru` / `GlideCopy`.
- Один SQL-предикат «будущий ОХМ» для чипа и фильтров.
- Один формат строки сеанса + тот же invite URL.
- Allow-list МК (`public_skate|open_ice`) не расширять ОХМ.

## Вне скоупа

ОФМ · запись/оплата ОХМ · Кобрин/Островец · отдельный лендинг `/ohm`.

## Срезы реализации (черновик)

1. **Прод-данные** — убедиться, что ingest четырёх катков пишет будущие `hockey_practice` (СДЮШОР — local egress).
2. **Место** — заменить сводку ОХМ на секцию слотов + условия + «позвать» (правка к TASK-211 / Place.html).
3. **Город + чип главной** — `?kind=ohm`, `hockey_href` больше не `null`.
4. **Mini App** — чип/режим «Хоккей (ОХМ)» на табе «Лёд», тот же API/фильтр.
