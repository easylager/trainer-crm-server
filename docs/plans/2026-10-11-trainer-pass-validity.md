# Срок жизни абонемента тренера

Тренер задаёт срок на типе абонемента и выдаёт его клиенту. Часы стартуют в момент выдачи. Уже выданный экземпляр хранит свою дату и не переписывается, если тренер потом изменит тип.

## Что делают похожие сервисы

| | YClients / Altegio | Mindbody |
|---|---|---|
| Где живёт срок | На типе абонемента | На pricing option |
| Типовые значения | 30, 90, 180, 365 дней, свой срок, без срока | Дни или месяцы с даты активации |
| Без срока | Только если число посещений ограничено | Пакет без срока не сгорает, пока им не воспользовались |
| Когда стартуют часы | С продажи или с первого посещения | С продажи, с первого визита или с выбранной даты |
| Если «с первого визита» и визита нет | Автоактивация через N дней после продажи, иначе часы не идут | Срок сам перекатывается вперёд, пакет можно держать бесконечно |
| После продажи | Срок типа не переписывает уже проданные абонементы | Смена активации задним числом — отдельное действие |
| Конец срока | Неиспользованный остаток сгорает | Сгорает в 23:59 даты окончания |
| Заморозка | Отдельная настройка типа, дни заморозки прибавляются к сроку | Отдельный контракт |

Источники: [срок и типы YClients](https://support.yclients.com/58-62-764--tipy-abonementov/), [заморозка YClients](https://support.yclients.com/58-62-165--zamorozka-abonementov/), [типы Altegio](https://alteg.io/ru/support/knowledge-base/4906188737437), [автоактивация Altegio](https://alteg.io/ru/support/knowledge-base/4906119610909), [pricing options Mindbody](https://support.mindbodyonline.com/s/article/213024177-Pricing-Options-screen).

Пример Altegio для регулярной услуги: 10 сеансов за три месяца. Наши коллективные пакеты тренера уже живут так же: 8 занятий — 90 дней, 16 — 150.

## Что сделано здесь

Выдача у нас происходит после оплаты вне платформы, клиент обычно уже занимается. Поэтому часы идут **с выдачи**, как у коллективных абонементов и как вариант «с момента продажи». Активация с первого визита без автоактивации оставляет оплаченный пакет открытым навсегда — это дыра, которую Mindbody описывает отдельно. Заморозку в этот заход не включаем.

Правила:

1. `validity_days` на типе: пусто — без срока, иначе 1–3650 дней.
2. Без срока допустим, потому что число занятий всегда ограничено.
3. При выдаче `expires_at = момент выдачи + validity_days`. Поле копируется на экземпляр.
4. Правка типа не двигает уже выданные абонементы.
5. После `expires_at` остаток нельзя списать ни автоматически, ни вручную, и этот экземпляр не мешает выдать новый.
6. Подсказка в форме, не обязанность: до 4 занятий — без срока, 5–8 — 90 дней, 9–12 — 120, 13–16 — 150, больше — 180. Это неделя на занятие и запас около двух недель, округление к срокам, которые студии реально продают.
