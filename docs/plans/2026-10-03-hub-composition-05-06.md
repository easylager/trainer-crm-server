## TASK-149 — в скоупе

1. Приветствие: «{Утро/День/Вечер}, {Имя}». Подпись только из фактов: город + N сеансов сегодня (из уже загруженного ice teaser / bootstrap). Нет имени — без имени. Нет сеансов — без счётчика, не «0 сеансов» как витрина.
2. Один блок льда: kicker «На льду сейчас · {Город}», герой = текущий ice teaser, 2–3 строки = `hub-ice-today-model`, ссылка «весь лёд». `renderIceTeaser` / `renderIceTodaySessions` не переписывать — сменить место в DOM и обёртку. Отдельного `#hubIceToday` внизу нет.
3. Поиск остаётся компактным (существующий `#hubSearchRow`). Имеет смысл вынести из «зоны льда» визуально, как в макете — строка между льдом и сеткой; поведение `navigate` не менять.
4. Одна навигация «Куда катимся»: светлые плитки, иконка типа на плашке (`--app-venue-*`), живой счётчик, строка ценности из уже известных подписей пресетов/фасетов, диплинк в каталог. Поглощает `#hubDiscovery` и `#hubCollections` как **два входа**. Пресеты 148 не удалять как модель — плитки/ссылки сетки. Слово «Подборки» как заголовок секции исчезает.
5. Плитка только при счётчике > 0. Состав **не обязан быть 2×2**: Катки (ice+outdoor), Тренеры, Магазины (shop). Нет ни одной плитки — секции нет.
6. Свой клиент: `placeIceZone` и Intent Engine не ломать по смыслу «своё сверху». Сетка рынка **ниже** персональных блоков. Разметку карточки записи/тренера/абонемента не переписывать.
7. Светлый холст. Новые стили — только `var(--app-*)` / `var(--glide-*)`. G-P1 не ухудшать. `?v=` поднять у затронутых ассетов.

### Слайсы 149

- **S1** Приветствие из фактов + подпись (город, счётчик). Не погода.
- **S2** Склеить лёд: teaser + строки today в одном `#hubIceZone` (или новой обёртке вокруг существующих id). Поиск — сразу под блоком. Тесты wiring.
- **S3** Сетка «Куда катимся» из модели коллекций + счётчик тренеров; discovery не дублирует ту же навигацию. Href «Сегодня вечером» / вечерняя плитка: `ice?city_id=&when=today_evening`. Прочитать `when` на boot в `ice-tab.js` (минимальный дифф, без фильтровой шторки).
- **S4** Порядок DOM гость vs свой клиент + кэш-версии + перенос инвариантов тестов 148.
