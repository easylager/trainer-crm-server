## Цель

Режим «Карта» во вкладке «Поиск» становится полноэкранным экраном карты по прототипу:
карта ~85% высоты, плавающий поиск и чипы, пины с временем сеанса, кластеры «N · с HH:MM»,
нижняя шторка (сводка → карусель → список), карусель синхронна с пинами, тёмная подложка в
тёмной теме, без +/−.

## Решения (зафиксированы)

1. **Остаёмся на Яндекс JS API 2.1.** Тёмная подложка — CSS-фильтр только на слое тайлов
   (`[class*="ground-pane"]`) в тёмной теме: `filter: invert(1) hue-rotate(180deg)
   brightness(.9) contrast(.9)` (подобрать по живой карте). Переезд на v3 (`theme: 'dark'`) —
   отдельная задача.
2. **Full-положение шторки = существующий списочный вид** (`state.view = 'list'`), а не
   второй список внутри шторки. Шторка на карте живёт в двух положениях: peek и half.
3. **Бэкенд не меняется.** Время в пине — `live.starts_at_local`; «вне окна» —
   `live.outside_window`; tier — `item.tier`.

## Этапы

### 1. Модель (`static/webapp/ice-map-model.js`) + тесты
- `pinView(item, { selected })` → `{ kind: 'time'|'dot', time, shortName, venue, selected }`:
  пилюля с временем для tier A/B с сеансом в окне; `dot` для tier C и `outside_window`.
  **Сломает текущие тесты** `pin chrome (A label, muted C)` — ярлык «Чижовка · 11:00»
  меняется на время в пине + имя только у выбранного. Тесты переписать под новый контракт.
- `clusterSummary(items)` → `{ count, minTime, hasHits, label }` («с 18:15» / «нет сеансов»).
- `railOrder(items)` → сначала места с сеансом в окне по времени, потом остальные.
- `sheetSummary(items, window)` → «7 мест сегодня вечером · 11 сеансов · ещё 2 без сеансов».
- `snapFor(heightPx, snaps)` → ближайшее положение шторки.

### 2. Слои карты (`static/webapp/ice-map.js`)
- `PinLayout`: разметка из прототипа (`.ice-ypin` → пилюля + хвост, модификаторы
  `--sel`, `--dot`, `--shop`, `--outdoor`). В 2.1 template-layout перестраивается при
  `placemark.properties.set(...)` — выделение менять через свойство `sel`.
  `iconShape` — прямоугольник под пилюлю (~[-36,-38]…[36,0]); для выбранного шире.
- `ClusterLayout`: `templateLayoutFactory.createClass(tpl, { build() {...} })` — в `build`
  вызвать superclass, взять `properties.get('geoObjects')`, посчитать `clusterSummary`,
  проставить текст и класс `--sel`/`--quiet`. `clusterIconShape` — прямоугольник ~100×36.
- `controls: []` — убрать `zoomControl`.
- Выделение: `selectedId` → у всех плейсмарков `properties.set('sel', id === selectedId)`.
- Карусель: заменить одиночную карточку `#iceMapSheet` на `.ice-map-rail` всегда (не только
  для кластера); `scroll` (debounce 120 мс) → выбрать карточку по центру → выделить пин →
  если пин вне видимой области (между плавающим верхом и шторкой) — `map.panTo`.
  Тап по пину → `rail.scrollTo` к карточке (на время программного скролла — лок, чтобы
  не словить обратную синхронизацию).
- `onClusterClick` оставить; шапка шторки при открытом кластере — «N места рядом»,
  тап по пустой карте (`map.events 'click'`) — сброс к общему набору.
- Камера: при вписывании учитывать высоту плавающего верха и шторки
  (`zoomMargin: [topUi + 56, 70, sheetH + 24, 70]`).

### 3. Экран (`static/webapp/ice.html`, `ice-tab.css`, `ice-tab.js`)
- `body.ice-view-map`: `.ice-map-stage` — `position: fixed; inset: 0; bottom: var(--client-shell-tab-inset)`;

- Шторка `#iceMapSheet` → `.ice-sheet` поверх карты: хэндл, шапка (сводка + «Списком»),

- Пилюля `#iceViewSwitch` в режиме карты скрыть (её роль у шторки); в списке — остаётся «Карта».

## Критерии приёмки

- AC-1. В режиме карты карта занимает всё пространство между верхом экрана и таб-баром;
  над ней плавают только строка поиска (с городом) и ряд чипов.
- AC-2. Пин места с сеансом в выбранном окне показывает время сеанса; выбранный пин залит
  брендом и показывает короткое имя; места без сеанса в окне — полые точки без текста.
- AC-3. Кластер показывает число мест и минимальное время («3 · с 18:15») либо «нет сеансов».
- AC-4. Тап по кластеру: все его места видны целиком (с ярлыками) между верхом и шторкой,
  zoom ≤ 16; места в одном комплексе — без зума, сразу карточками.
- AC-5. Шторка: peek/half на карте, свайп/кнопка «Списком» ведёт в список; карусель
  синхронна с пинами в обе стороны.
- AC-6. В тёмной теме подложка тёмная, пины и кластеры не инвертированы.
- AC-7. Нет кнопок +/−; «Где я» — круглая кнопка над шторкой.
- AC-8. JS-тесты зелёные; обновлённые тесты описывают новый контракт, а не удалены.

## Риски

- **CSS-фильтр на тайлах** — цвета приблизительные, на слабых телефонах фильтр может стоить
  FPS при панорамировании. Если заметно — отключить фильтр и ускорить переезд на v3.
- **Template-layout 2.1** перестраивает DOM на каждое `properties.set` — при 50 пинах
  выделение трогать только у двух плейсмарков (старый и новый выбранный), не у всех.
- **Скролл-синхронизация** легко зацикливается (скролл → выделение → скролл). Лок на время
  программного скролла обязателен (сделано в прототипе).
- **Telegram WebView**: `position: fixed` + свайп шторки конфликтует со свайпом закрытия
  мини-аппа — вызвать `Telegram.WebApp.disableVerticalSwipes()` в режиме карты (проверить,
  что уже не вызывается в shell).
- Проверка без живого Яндекса неполная: финальное слово — владелец на устройстве.
