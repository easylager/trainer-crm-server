# Промты для унификации мини-приложений под `schedule.html`

Единая визуальная база: **`static/webapp/schedule.html`** (паттерны карточек, чипов, hero, кнопок) + **`static/webapp/theme.css`** (токены `--tg-theme-*` / `--app-*`).

---

## База: что взять из расписания

### Токены и фон (`theme.css`)

| Роль | Светлая тема | Тёмная тема |
|------|----------------|-------------|
| Фон | `--tg-theme-bg-color` (`#fffbec`) | `#000000` |
| Поверхности / карточки | `--tg-theme-secondary-bg-color` (`#fff5e1`) | `#1c1c1e` |
| Текст | `--tg-theme-text-color` | `#ffffff` |
| Подсказки | `--tg-theme-hint-color` | `#8e8e93` |
| Акцент кнопок | `--tg-theme-button-color` (`#f5a623`) | то же |
| Текст на кнопке | `--tg-theme-button-text-color` | `#1a1a1a` |

### Паттерны из `schedule.html`

- Подключение: `theme.css`, `telegram-web-app.js`, шрифт **DM Sans** (Google Fonts) для премиальных / детальных блоков (как экран детали записи `#screenDetail`).
- Карточки слотов: `border-radius: 12px`, фон `var(--tg-theme-secondary-bg-color)`; акцент — бордер `rgba(247, 166, 0, 0.45)` где уместно.
- Фильтры: чипы `border-radius: 20px`, активное состояние через `--tg-theme-button-color` / `--tg-theme-button-text-color`.
- Hero и акценты: градиент `linear-gradient(155deg, rgba(247, 166, 0, 0.14) …)`, обводка `rgba(247, 166, 0, 0.28)`, тень, радиальный блик `rgba(247, 166, 0, 0.22)`.
- CTA: оранжевый `#F7A600`, градиент кнопки `#ffc23d` → `#f0a000`, вторичный крем `#FFF3CC`, опасные действия — красные полупрозрачные стили (как в `.bd-btn--outline-danger`).
- Статусы: зелёный `#34c759`, оранжевый для «занято», приглушённый для отмены — в духе `.slot-status.*`.
- Микродвижение: например `animation` с `cubic-bezier(0.22, 1, 0.36, 1)`, лёгкий `:active` на кнопках.

### Обязательная фраза для промта

Вставляйте в конец каждого запроса к ассистенту:

> **Сделай дизайнерский шедевр, опираясь на визуальный шаблон `static/webapp/schedule.html` и токены `static/webapp/theme.css` (кремовый/янтарный светлый режим; тёмный — чёрный фон и карточки `#1C1C1E`; акцент янтарь `#f5a623` / `#F7A600`; карточки ~12px; чипы ~20px; hero с янтарным градиентом и мягкой тенью; DM Sans для иерархии заголовков/детальных экранов). Сохрани поведение и разметку; меняй визуал и UX-полировку.**

## Универсальный промт

Подставьте имя файла вместо `<ИМЯ>.html`.

```text
Переделай мини-приложение static/webapp/<ИМЯ>.html под единый стиль с static/webapp/schedule.html: те же CSS-переменные из theme.css, те же принципы карточек, чипов, кнопок и hero-блоков с янтарным градиентом. Сделай дизайнерский шедевр, опираясь на визуальный шаблон schedule.html и токены theme.css (кремовый/янтарный светлый режим, тёмный с чёрным фоном и карточками #1C1C1E, акцент янтарь, DM Sans где уместно для иерархии). Не ломай логику и API-вызовы; только стили, типографика, отступы, состояния hover/active, пустые и ошибочные экраны.
```

## Промты по страницам

Для каждой страницы: скопируйте блок + при необходимости добавьте универсальную фразу выше.

### Клиент

| Файл | Фокус промта |
|------|----------------|
| `book.html` | Шаги бронирования, primary CTA как в schedule (hero + янтарные кнопки). |
| `catalog.html` | Сетка карточек тренеров: 12px, мягкая тень, янтарь на hover/выбранном. |
| `client-bookings.html` | Список записей как дни в schedule: uppercase подзаголовки дней, карточки как `.slot-card`. |
| `client-buy-pass.html` | Hero с градиентом, кнопки как `.bd-btn--primary`. |
| `client-passes.html` | Карточки абонементов — вторичный фон + статус-бейджи как `.slot-status`. |
| `client-passes-certificates.html` | Единая сетка passes + сертификаты; DM Sans для заголовков секций. |
| `client-certificates.html` | Минималистичные карточки, янтарь на важных действиях. |
| `client-requests.html` | Чипы фильтров как `.filter-btn`, карточки заявок как слоты. |

| Файл | Фокус промта |

| `trainer-pass-products.html` | Карточки продуктов с янтарным акцентом и вторичными кнопками. |
