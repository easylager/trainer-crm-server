# PDF-сертификат: требования к макету и интеграция

## Проблема «двойного текста»

Если в экспорте PDF остаются строки вида `{recipient_name}` или демо-данные, они **рисуются как обычный текст**. Код **не удаляет** их — только может наложить новый слой. Итог: плейсхолдеры и реальные данные видны одновременно.

## Что передать дизайнеру

**Задача:** подготовить макет под **программную подстановку** (Python → PDF).

1. Убрать из финального экспорта всё динамическое: плейсхолдеры `{...}`, примеры имён, сумм, кодов, дат, тестовый код крупным шрифтом.
2. Оставить статичный декор: фон, подписи полей («НОМИНАЛ», «КОД АКТИВАЦИИ»), рамки, пустая область под QR.
3. Экспорт без водяных знаков инструментов на проде.
4. **Опционально (лучший вариант):** в Acrobat / InDesign добавить **поля формы (AcroForm)** с именами ниже — тогда координаты в коде не подбираются.

## Имена полей AcroForm (если делаете форму)

| Имя поля | Содержимое |
|----------|------------|
| `recipient_name` | Имя получателя |
| `product_title` | Название продукта сертификата |
| `amount` | Сумма (только число или «Любая сумма») |
| `amount_currency` | Например `BYN` |
| `trainer_display_name` | ФИО тренера |
| `expires_at` | Дата окончания или «бессрочно» |
| `issued_at` | Дата выдачи |
| `code` | Код активации |
| `purchased_by_name` | От кого подарок (может быть пусто) |
| `footer_hint` | Короткая инструкция (опционально) |

Рантайм заполняет совпадающие поля автоматически.

## Оверлей по координатам

Если формы нет, координаты задаются в [`static/templates/certificate_layout.json`](../static/templates/certificate_layout.json): доли страницы (0–1), начало координат — **левый верх** (`x0`, `y0` — левый верх, `x1`, `y1` — правый низ).

После смены макета подстройте YAML под новый PDF.

## Текущий шаблон по умолчанию

В репозитории лежит **программно сгенерированный** фон без динамических данных (`certificate_template.pdf`). Пересобрать: `python scripts/generate_certificate_template.py`. Файл можно **заменить** экспортом от дизайна (подстройте [`static/templates/certificate_layout.json`](../static/templates/certificate_layout.json) под новый размер/вёрстку).
