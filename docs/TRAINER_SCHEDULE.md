# Расписание тренера

Слоты привязаны к **календарным неделям** (Пн–Вс). Текущая и следующая неделя планируются отдельно: можно во вторник выставить другое расписание на следующую неделю, не трогая эту.

## Модели

- **trainer_schedule_templates** — шаблон (день + время + длительность) для быстрого применения к неделе.
- **slots** — слоты с датой: `trainer_id`, `slot_date`, `start_time`, `end_time`, `status`. Создаются на выбранную неделю.

## Сценарий в боте (UX)

- **Шаблон** — образец недели (день + время). Изменения в шаблоне не трогают уже созданные слоты на неделях.
- **Добавить на неделю из шаблона** — слоты из шаблона **дополняют** уже стоящие на выбранной неделе; совпадающие по времени не дублируются. Ничего не перезаписывается.
- **Мои слоты** — экран «что видят клиенты» (текущая + следующая неделя), с кнопками удаления свободных слотов и возвратом в «Расписание».

1. **Расписание** — блок «Твой шаблон», кнопки: **«Мои слоты»**, **«Добавить слоты вручную на неделю»**, **«Добавить на эту/следующую неделю из шаблона (dd.mm–dd.mm)»**, под каждым слотом шаблона — удаление из шаблона.
2. **Добавить слоты** → «Куда?» → **В шаблон** | **Эта неделя** | **Следующая неделя** → день → мультивыбор часов → длительность.
3. **Мои слоты** (из меню /slots или кнопка в Расписании) — список слотов по неделям, кнопки «❌ dd.mm HH:mm» для удаления свободных слотов, внизу «◀️ Расписание».

## Миграция

```bash
alembic upgrade head
```

Дальше: на стороне клиента — показ доступных слотов выбранного тренера и создание записи (booking).
