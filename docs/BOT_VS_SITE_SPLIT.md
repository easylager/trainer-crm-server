# Что оставлять в боте, что переносить на сайт

Честная оценка текущего функционала: где бот удобен, где упрётся в ограничения Telegram и лучше дать ссылку на сайт.

---

## Принцип

- **В боте сильно:** уведомления, 1–3 тапа до действия, короткие списки, «написать в чат», быстрые ответы (подтвердить/отменить).
- **В боте слабо:** долгий выбор из каталога, календарь/сетка, много полей ввода, дашборды, объёмные отчёты.

---

## Клиентский бот

| Функция | Оценка | Рекомендация |
|--------|--------|--------------|
| **Каталог** (город → услуга → арена → тренеры, пагинация) | В боте много тапов, нет фильтров и карточек с фото. Удобно только если тренеров мало. | **Перенести на сайт** основной просмотр: фильтры, карточки тренеров с фото, кнопка «Записаться» → открывает бота по deep link с `trainer_id`. В боте оставить короткий путь «записаться к выбранному» для тех, кто уже выбрал тренера (с сайта или в прошлый раз). |
| **Запись на слот** (выбор слота → телефон → коммент) | Нормально в боте: 3–4 шага, один ввод (телефон). | **Оставить в боте.** Можно запускать из бота или по deep link с сайта («Записаться» на сайте → бот с уже выбранным тренером). |
| **Мои записи** (список, ссылка на тренера, отмена) | Очень удобно: быстрый просмотр, действие в 1–2 тапа. | **Оставить в боте.** |
| **Заявка «не нашёл тренера»** (город, услуга, комментарий) | Короткая форма, мало полей. | **Оставить в боте.** |
| **Мои заявки** (список, отклики) | Короткий список, просмотр. | **Оставить в боте.** |
| **Напоминания 24ч / 2ч, уведомление об отмене** | Сильная сторона мессенджера: приходят туда, где человек уже сидит. | **Только в боте**, на сайте такого нет. |
| **«Занятие прошло» → отзыв** | Один тап из уведомления. | **Оставить в боте.** |
| **Инструкция, настройки (город/услуга/арена)** | Текст + кнопки. | **Оставить в боте.** |

**Итог по клиенту:** каталог и «выбор тренера» логично делать на сайте; запись, мои записи, заявки, уведомления и отзывы — в боте. Сайт может вести на бота с уже выбранным тренером.

## Тренерский бот

| Функция | Оценка | Рекомендация |
|--------|--------|--------------|
| **Расписание** (шаблоны, слоты по неделям, выбор дня/времени) | В боте много экранов и кнопок; нет календаря и массового выбора. | **Перенести на сайт (ЛК тренера):** календарь, массовое создание слотов, шаблоны. В боте оставить просмотр «моя неделя» и быстрые действия (одна кнопка «открыть расписание на сайте»). |
| **Мои записи** (список, написать клиенту, отменить) | Удобно: список + кнопки под записью. | **Оставить в боте.** |
| **Заявки клиентов** (список, откликнуться) | Короткий список, одно действие. | **Оставить в боте.** |
| **Уведомления** (новая запись, новая заявка, «оставь отзыв») | Ключевая ценность: тренер сразу видит в Telegram. | **Только в боте.** |
| **Статистика** (/stats: неделя, месяц, загрузка) | Короткий текст — норм в боте. | **Оставить в боте.** Детальные отчёты, графики, экспорт — делать на сайте. |
| **Редактирование профиля** (много полей, фото) | В боте неудобно: много шагов, загрузка фото через бота ограничена. | **Перенести на сайт** (ЛК тренера). В боте — ссылка «Профиль на сайте». |

**Итог по тренеру:** расписание и профиль — на сайте; записи, заявки, уведомления и краткая статистика — в боте.

## Админ-бот

| Функция | Оценка | Рекомендация |
|--------|--------|--------------|
| **Модерация** (/pending: одобрить/отклонить/правки) | Быстрые действия по одной карточке. | **Оставить в боте.** |
| **Статистика** (/stats) | Короткие цифры. | **Оставить в боте.** Объёмные отчёты и управление справочниками — на сайте админки. |
| **Справочники** (города, арены, услуги) | Много сущностей, CRUD — в боте неудобно. | **Перенести на сайт** (админ-панель). |

**Итог по админу:** очередь модерации и краткий /stats — в боте; всё остальное админское — на сайте.

## Сводная таблица

| Что | Где лучше | Примечание |
|-----|-----------|------------|
| Уведомления (напоминания, новая запись, отмена, «оставь отзыв») | Бот | Не переносить. |
| Запись на слот (выбор слота, телефон) | Бот | Запуск с сайта по deep link — ок. |
| Мои записи / мои заявки (просмотр, отмена, написать) | Бот | Оставить. |
| Заявка «не нашёл тренера» | Бот | Оставить. |
| Каталог (выбор тренера, фильтры, карточки с фото) | Сайт | В боте — только «записаться к уже выбранному» или короткий список. |
| Расписание тренера (календарь, слоты, шаблоны) | Сайт | В боте — просмотр + ссылка «Редактировать на сайте». |
| Профиль тренера (много полей, фото) | Сайт | В боте — ссылка на ЛК. |
| Модерация тренеров (/pending) | Бот | Оставить. |
| Детальная статистика, отчёты, экспорт | Сайт | В боте — только краткий /stats. |
| Справочники (города, арены, услуги) | Сайт (админка) | В боте не делать. |
| Оплата подписки (выбор тарифа, платёжная страница) | Сайт | Бот может показывать ссылку и уведомлять «Оплачено». |

## Практический сценарий

1. **Сейчас:** всё, что уже есть в ботах, оставляем; дорабатываем UX (кнопки, короткие тексты, ссылки на тренера).
2. **Когда появится сайт:**  
   - Клиент: каталог и выбор тренера — на сайте; кнопка «Записаться» открывает бота с `?start=book_<trainer_id>`. Запись, мои записи, заявки, уведомления — только в боте.  
   - Тренер: расписание и профиль — в ЛК на сайте; в боте — «Мои записи», «Заявки», уведомления и кнопка «Расписание на сайте».  
   - Админ: модерация и /stats в боте; справочники и сложная аналитика — в веб-админке.
3. **Бот не заменяют сайтом** — бот остаётся точкой входа для уведомлений и быстрых действий; сайт забирает только тяжёлые сценарии (каталог, календарь, формы, отчёты).

Так боты остаются максимально удобными для того, что в Telegram делается хорошо, а неудобное переносится на сайт без перегрузки бота.
