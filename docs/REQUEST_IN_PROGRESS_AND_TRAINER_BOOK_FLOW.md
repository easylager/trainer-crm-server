# Заявка «В процессе» и флоу «Тренер записывает клиента»

## Цели

1. **Заявка не исчезает у тренера** после отклика — остаётся в списке в статусе «В процессе» (откликнувшиеся тренеры по-прежнему видят заявку).
2. **Клиент после отклика** может: сразу записаться ИЛИ написать тренеру в ЛС.
3. **После переписки в ЛС** клиент может записаться сам, либо тренер пообещает записать позже.
4. **«Гениальная система»**: если тренер пообещал записать позже — система напоминает ему, когда появятся свободные слоты; тренер записывает клиента с привязкой к заявке → заявка архивируется, клиент получает уведомление.

---

## Текущее состояние

- Заявки с откликом тренера **не показываются** в списке тренера (фильтр `NOT EXISTS client_request_responses`).
- Запись с привязкой к заявке есть только со стороны **клиента** (кнопка «Записаться» у отклика → слот → `create_booking(client_request_id=...)`).
- Тренер **не может** создать запись по заявке из бота.
- Нет сущности «пообещал записать потом» и напоминаний тренеру при появлении слотов.

---

## Целевой флоу

### 1. Список заявок у тренера

- Показываются и **новые** (можно откликнуться), и **те, на которые тренер уже откликнулся** («В процессе»).
- У каждой заявки в списке подпись: «Готов взять» / «Вы откликнулись» (как сейчас в детали).

### 2. Детали заявки, на которую тренер откликнулся

Кнопки:

- **«✉️ Написать клиенту»** — ссылка `tg://user?id={client_telegram_id}`.
- **«Записать клиента»** — переход к выбору своего свободного слота → создание записи с привязкой к заявке → архив заявки, уведомление клиенту.
- **«Напомнить когда появятся слоты»** — тренер пообещал записать позже; система запоминает и будет напоминать при появлении свободных слотов.

### 3. Напоминание тренеру при появлении слотов

- Раз в N часов (например, раз в день) проверка: у кого есть «пообещал записать» и при этом есть хотя бы один **свободный слот** в будущем.
- Такому тренеру: «У вас заявка в работе — клиент ждёт записи. Есть свободные слоты: запишите его.» + кнопка «Записать клиента» (ведёт на флоу записи по этой заявке).

### 4. Запись тренером по заявке

- Тренер выбирает слот (только свои, доступные, в будущем).
- Создаётся `booking` с `client_request_id`, клиент берётся из заявки.
- Заявка переводится в `archived`.
- Клиенту отправляется уведомление от **клиентского бота**: «Вас записал тренер {name} на {date} {time}.»

### 5. Отличие от записи клиентом

- Когда запись создаёт **клиент** (кнопка «Записаться» у отклика), он сразу видит успех в том же флоу; дополнительное уведомление «Вас записал тренер» не нужно.
- Когда запись создаёт **тренер**, клиент не в боте — нужно одно уведомление «Вас записал тренер…». Для этого в БД помечаем, что это «запись от тренера», и клиентский бот по ней один раз шлёт сообщение.

## Изменения в данных и коде

| Что | Детали |
|-----|--------|
| **list_requests_for_trainer** | Убрать исключение по «уже откликался»; добавить в выдачу `client_id`, `client_telegram_id` для кнопки «Написать» и для записи. |
| **Экран детали заявки (has_responded)** | Кнопки: Написать клиенту, Записать клиента, Напомнить когда появятся слоты. |
| **Таблица trainer_pending_request_booking** | `(trainer_id, client_request_id, created_at [, last_reminder_sent_at])` — тренер пообещал записать по этой заявке. |
| **create_booking** | Параметр `created_by_trainer: bool`. Если True и задан `client_request_id` — не выставлять `client_notified_trainer_booked_at`, чтобы клиентский бот отправил уведомление. Если False (клиент записался сам) — выставить `client_notified_trainer_booked_at = now()`, чтобы не дублировать. |
| **bookings.client_notified_trainer_booked_at** | Nullable timestamp. Null = клиенту ещё не отправлено «Вас записал тренер». Клиентский бот: выборка по `client_request_id IS NOT NULL AND client_notified_trainer_booked_at IS NULL`, отправка, проставление поля. |
| **Use case: запись тренером** | Получить по `request_id` и `trainer_id` клиента заявки (с проверкой, что тренер откликался); список слотов тренера (available, в будущем); вызов `create_booking(..., client_request_id, created_by_trainer=True)`. |
| **Цикл в тренерском боте** | «Pending request + есть слоты» → уведомление тренеру с кнопкой «Записать клиента», не чаще раза в 24 ч на пару (trainer, request). |
| **Цикл в клиентском боте** | Новый: выборка букингов «запись от тренера по заявке, клиенту ещё не уведомляли» → отправить «Вас записал тренер…» и проставить `client_notified_trainer_booked_at`. |

## Реализовано

1. **Список заявок** (`list_requests_for_trainer`): показываются и новые, и откликнувшиеся; в выдаче есть `client_id`, `client_telegram_id`.
2. **Экран «Вы откликнулись»**: кнопки «✉️ Написать клиенту», «Записать клиента», «Напомнить когда появятся слоты», «◀️ К списку заявок».
3. **Миграция 0033**: таблица `trainer_pending_request_booking` (trainer_id, client_request_id, created_at, last_reminder_sent_at), колонка `bookings.client_notified_trainer_booked_at`.
4. **Use cases**: `get_request_client_for_trainer_booking`, `add_trainer_pending_request_booking`, `clear_trainer_pending_request_booking`, `get_trainers_pending_request_with_slots`, `mark_trainer_pending_request_reminder_sent`; `create_booking(created_by_trainer=...)`; `get_pending_trainer_booked_notifications`, `mark_trainer_booked_notified`.
5. **Тренер-бот**: флоу «Записать клиента» (выбор слота → create_booking с привязкой к заявке), обработка «Напомнить когда слоты», цикл `_pending_request_slots_reminder_loop` (раз в час, не чаще раза в 24 ч на пару тренер–заявка).
6. **Клиент-бот**: цикл `_trainer_booked_notifier_loop` — уведомление «Вас записал тренер … на дату (день) время».
