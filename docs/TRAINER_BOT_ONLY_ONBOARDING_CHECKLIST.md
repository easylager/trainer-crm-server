# Чеклист: новый тренер только в боте (до одобрения)

Ручной сценарий для регрессии гейта и профиля. Тексты и кнопки — `src/bot/messages.py`, команды меню — `src/bot/trainer_app.py`.

После одобрения см. [Первый день тренера в боте](./TRAINER_ONBOARDING_FIRST_DAY.md).

## Предусловия

- [ ] В БД есть тренер без привязанного Telegram (или тестовый аккаунт).
- [ ] Есть одноразовая ссылка `t.me/<trainer_bot>?start=link_<token>`.
- [ ] Админ-бот запущен, админ может вызвать `/pending` и одобрить.

## Шаги

1. **Привязка**  
   - [ ] Открыть бота по ссылке, `/start`.  
   - [ ] Ожидается: сообщение о привязке + текст гейта (не обещание полного меню, если ещё не `active`).

2. **Заполнение анкеты**  
   - [ ] `/myprofile` → «Изменить по шагам», пройти шаги до конца (имя, фамилия, возраст, контакты, описание, город, услуги и т.д.).  
   - [ ] `/profile` — карточка и подсказка гейта согласованы с фактическим состоянию.

3. **Фото**  
   - [ ] В хабе `/myprofile` → «Фото профиля» (или фото в конце мастера).  
   - [ ] Отправить фото или image-документ; при ошибке — понятный текст, повтор возможен.  
   - [ ] В админ-карточке тренера фото отображается.

4. **Отправка на модерацию**  
   - [ ] В `/myprofile` кнопка «Готово — отправить на модерацию».  
   - [ ] Подтверждение об отправке; повтор без изменений профиля — сообщение «уже в очереди».  
   - [ ] Админ получает карточку в Telegram (если настроены `telegram_bot_token_admin` и `admin_telegram_ids`).

5. **Модерация**  
   - [ ] `/pending` в админ-боте — тренер в списке.  
   - [ ] Одобрение → статус `active`.

6. **Доступ к функциям**  
   - [ ] `/start` — приветствие с полным меню.  
   - [ ] Команда вне allowlist (например расписание) не показывает только гейт — открывается рабочий сценарий.

## Автотесты (pytest)

- `tests/application/test_trainer_profile_completeness.py` — фикстуры агрегата и `is_profile_complete_for_moderation`.  
- `tests/bot/test_trainer_gate_middleware.py` — блокировка «рабочего» хендлера при `BLOCKED_PROFILE` и проход allowlisted `/myprofile`.
