# Визуальная конституция мини-приложения тренера (экран детали записи)

Документ задаёт **жёсткие правила** визуального языка CRM: любой экран тренерского мини-приложения должен выглядеть как продолжение **этого** интерфейса, а не как отдельный дизайн.

**Эталон визуала:** тёмный экран «Запись» с блоком времени (hero), карточкой клиента, группой строк «Подробности» и кнопками действий — см. реализацию в [`static/webapp/schedule.html`](../static/webapp/schedule.html) (рендер `booking-detail` в `openDetail`) и стили в [`static/webapp/mini-app-components.css`](../static/webapp/mini-app-components.css). Статичный референс-скрин: [`docs/assets/trainer-booking-detail-reference.png`](assets/trainer-booking-detail-reference.png).

**Иерархия источников правды (сверху вниз — не нарушать):**

1. [`static/webapp/theme.css`](../static/webapp/theme.css) — только токены (`--tg-theme-*`, `--app-*`, семантика `--app-danger` / `--app-success`).
2. [`static/webapp/mini-app-components.css`](../static/webapp/mini-app-components.css) — готовые классы shell, hero, карточек, кнопок, типографики детального экрана.
3. Локальный `<style>` в конкретной HTML-странице — **только** для уникальной вёрстки этой страницы; **запрещено** дублировать уже существующие правила из п. 1–2.

---

## 1. Светлая и тёмная тема

Поддерживаются обе; токены переключаются через `prefers-color-scheme` в `theme.css` и/или скрипты блокировки Telegram `themeParams`.

| Роль | Токен | Светлая (пример) | Тёмная (пример) |
|------|--------|------------------|-----------------|
| Фон приложения | `--tg-theme-bg-color` | `#fffbec` | `#000000` (глубокий матовый чёрный; допустим визуальный близкий оттенок `#121212` только через токен, не отдельным hex в разметке) |
| Поверхности / карточки | `--tg-theme-secondary-bg-color` | `#fff5e1` | `#1c1c1e` |
| Основной текст | `--tg-theme-text-color` | `#1a1a1a` | `#ffffff` |
| Подписи, метки, secondary | `--tg-theme-hint-color` | `#666` | `#8e8e93` |
| Акцент (кнопки, ссылки, иконки-детали) | `--tg-theme-button-color` | `#f5a623` | `#f5a623` |
| Текст на янтарной кнопке | `--tg-theme-button-text-color` | `#1a1a1a` | `#1a1a1a` |
| Опасное действие | `--app-danger` | `#ff3b30` | то же |
| Успех | `--app-success` | `#34c759` | то же |

**Запрещено:** вводить второй «брендовый» акцент (например системный синий `#5AC8FA`) для ссылок в наших стилях. Телефон и иные действия в макете — через `var(--tg-theme-button-color)` (класс `.bd-tel`). Системный WebView может отрисовать `tel:` иначе — не переопределять ради «как в iOS» отдельным цветом в CSS.

## 2. Типографика

| Элемент | Правило | Классы / место в коде |
|-----------|---------|------------------------|
| Экран детали записи | **DM Sans** для иерархии | `#screenDetail` в `mini-app-components.css` |
| Заголовок экрана (крошка) | Uppercase, плотный трекинг, приглушённый цвет | `.bd-screen-title` |
| Kicker блока времени | 11px, semibold, uppercase, letter-spacing ~0.14em | `.bd-hero-kicker` |
| Главное время | Крупный bold, отрицательный трекинг, clamp | `.bd-hero-time` |
| Дата/день под временем | 14px, medium, цвет hint | `.bd-hero-date` |
| Имя клиента | 17px semibold | `.bd-client-name` |
| Метки строк («Услуга · арена») | 10px, uppercase, letter-spacing ~0.08em, hint | `.bd-row-label` |
| Значения строк | 15px, line-height ~1.45 | `.bd-row-value` |
| Пользовательский комментарий | **Курсив**, чуть меньше размер | `.bd-comment .bd-row-value` |

Остальные экраны списков могут оставаться на системном стеке шрифтов из `body`; детальные и «премиальные» блоки — **DM Sans**, как на эталоне.

## 3. Цветовые градиенты и «свечение»

Эти приёмы **не выдумывать заново** — копировать из `mini-app-components.css`.

**Hero времени (`.bd-hero`):**

- Фон: `linear-gradient(155deg, rgba(247, 166, 0, 0.14) 0%, rgba(247, 166, 0, 0.04) 48%, transparent 100%)`.
- Обводка: `1px solid rgba(247, 166, 0, 0.28)`.
- Тень: `0 8px 32px rgba(0, 0, 0, 0.12)` (в тёмной теме читается как мягкая глубина).
- Псевдоэлемент `::before`: радиальный блик `radial-gradient(ellipse, rgba(247, 166, 0, 0.22) 0%, transparent 70%)` в правом верхнем секторе — создаёт «янтарное свечение» за карточкой.

**Аватар инициалов (`.bd-avatar`):**

- Заливка: `linear-gradient(145deg, #ffc23d 0%, #f7a600 55%, #e89400 100%)`.
- Текст инициалов: `#1a1a1a`.
- Свечение: `box-shadow: 0 4px 16px rgba(247, 166, 0, 0.4)`.

**Иконки в строках (`.bd-icon`):** `color: #f7a600`, stroke-иконки, opacity ~0.92.

## 4. Карточки и списки

| Компонент | Поведение |
|-----------|-----------|
| Карточка клиента `.bd-client` | `border-radius: 18px`, фон `var(--tg-theme-secondary-bg-color)`, тонкая рамка `rgba(128,128,128,0.14)`, лёгкая тень. |
| Группа строк `.bd-rows` | `border-radius: 16px`, внешняя обводка `rgba(128,128,128,0.12)`. |
| Строка `.bd-row` | Разделители `border-bottom: 1px solid rgba(128,128,128,0.08)`; иконка слева, текст справа; padding вертикальный ~14–16px. |

Радиусы кнопок в блоке действий: **14px** (`.bd-btn`); слоты в списке расписания: **12px** (`.slot-card`) — внутри одного приложения не смешивать без причины.

## 5. Кнопки и действия

**Токены:** `--app-btn-radius`, `--app-btn-padding`, `--app-btn-font-size`, `--app-btn-stack-gap` в `theme.css`; реализация — `mini-app-components.css`.

| Класс | Назначение |
|-------|------------|
| `.btn-primary` / `.bd-btn--primary` | Главный CTA: заливка `--app-cta-fill`, тень `--app-btn-shadow-cta` (нейтральная, без цветного ореола). |
| `.btn-secondary` / `.bd-btn--secondary` | Контур янтаря, **без** тени. |
| `.btn-outline-danger` / `.bd-btn--outline-danger` | Деструктивное outline, без тени. |
| `.btn-danger` | Мягкая заливка (модалки, компактные действия). |
| `.btn-message` / `.bd-btn--surface` | Третичные действия (карта, копировать телефон, написать): фон `--tg-theme-secondary-bg-color`, тень `--app-btn-shadow-surface`. |
| `.btn-soft` / `.bd-btn--soft` | Мягкий янтарный акцент (регулярность и т.п.): та же поверхностная тень, что у tertiary. |
| `.btn-neutral` | То же визуально, что surface/tertiary; для обновления списка и второстепенных кнопок. |
| `.btn-block` | На всю ширину контейнера (часто вместе с вариантом выше). |
| `.bd-btn--primary` / `--message` / `--outline-danger` | Алиасы для блока действий детали записи; те же визуальные роли. |

Все основные действия в колонке — **на всю ширину**, вертикальный стек: `gap: var(--app-btn-stack-gap)` (см. `.bd-actions-wrap`, `.btn-stack`).

## 6. Анимация и интерактив

- Появление детали записи: `.booking-detail` + `animation: bd-enter` — `0.38s cubic-bezier(0.22, 1, 0.36, 1)`.
- Нажатие кнопки: лёгкий `scale(0.985)` и снижение opacity на `:active` у `.bd-btn`.
- Фокус: кольцо из `theme.css` (`:focus-visible` с `--tg-theme-button-color`).

---

## 7. Сетка отступов

Базовая сетка **8px**: кратные 8 для gap и padding (12px body — допустимый внешний отступ экрана; внутри блоков — 8 / 16 / 24).

- Между секциями: 16px.
- Между кнопками в колонке: 10px.
- Горизонтальные поля контента: согласовать с `body` padding в `mini-app-components.css` (12px + safe-area).

---

## 8. Чеклист для агента перед сдачей страницы

1. Подключены `theme.css` и `mini-app-components.css` в указанном порядке.
2. Нет новых «сырых» `#rrggbb` на фоне и карточках — только токены и приёмы из §3–4.
3. Детальные экраны с hero/карточками/строками используют классы `.bd-*`, а не самописные копии.
4. Комментарии пользователя — курсивом (`.bd-comment`), метки — uppercase muted.
5. Проверены **светлая** и **тёмная** тема ОС.
6. Поведение и API не сломаны; меняется только визуальный слой.
