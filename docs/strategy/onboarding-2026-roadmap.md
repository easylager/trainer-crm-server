## Самое главное (TL;DR)

| Что | Зачем |
|-----|-------|
| **Удалить полноту + песочницу + гейты** | Раньше первая настоящая запись = сигнал успеха; сейчас это теряется в 200 строк ветвлений |
| **Сетка недели вместо анкеты** | Тренер видит свой вариант рабочего дня, не заполняет поля |
| **Мерить время до записи, не заполненость профиля** | Заполненость = обман: выглядит работает, на самом деле тренер не работает |
| **Триал по 20 записям, не дням** | Таймер не истекает, если тренер активен; активность = триал продлевается |
| **Каталог только при 5+ записях** | Сейчас каталог пуст на первой неделе = обещание невыполнимо = доверия нет |
| **Маркетинг на один каток, не город** | Сотни ледовых тренеров = малый ARPU; один каток = бизнес для катка = инфраструктура |

## Инварианты (перестроить вокруг них, не вокруг экранов)

1. **Ответ есть прямо сейчас** — не ждём ввод, не ждём модерацию
2. **Ничего не спрашиваем, пока не блокирует действие с живым человеком** — имя нужно при записи клиента, площадка — при первой записи, остальное — потом
3. **Пустой экран с призывом заполнить — баг проектирования** — если экран не может действовать, это плохо спроектировано
