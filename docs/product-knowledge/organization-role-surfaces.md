# Организации: что видит каждый

Черновик продуктового контракта — **что доступно в интерфейсе** по типу пользователя.

**Связанные решения (кратко):**

- **Оператор org** — одна роль (не делим owner / admin): операционка, команда, биллинг, бренд.
- **Member** — только личный контур: личная ссылка, без записи клиентов в org и без настроек бренда.
- **Несколько org + личная практика** — единое расписание; при создании слота/записи выбирается контекст («личное» / «организация X»), без переключателя org в шапке.
- **Две модели org:** «площадка» (центр, сетка) и «коворкинг» (студия, roster).
