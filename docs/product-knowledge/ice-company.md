# Компания на лёд

Сбор на один сеанс: одна карточка в чате и на `/k/{code}`, ответы «Иду / Может / Не могу», название команды. Зов (`/zovi`, `ice_invites`) это не заменяет.

**Канал для участников — живая PNG-карточка в чате** (обновляется по `card_dirty`). Личные напоминания и прочие DM участникам не шлём.

**Тон — компания друзей, не корпоративный сервис.** Название команды — главный мем на плакате внизу картинки. Модерация минимальная: без ссылок и HTML-скобок. Ники на льду — из Telegram или как человек ввёл при «Иду».

Флаг: `ICE_COMPANY_CITY_IDS` — список `city_id` через запятую. Пусто — фича выключена. Уже созданные ссылки `/k/{code}` открываются.

Срок хранения строк: `ICE_COMPANY_RETENTION_DAYS` (по умолчанию 30) после конца сеанса.

Организаторские действия требуют `initData` клиентского бота. Веб и Viber отвечают анонимным токеном. Повтор того же ключа меняет статус.

Статусы компании: `open`, `cancelled`, `expired`. Порога и стадии `confirmed` нет — карточка показывает, кто идёт, и шутку `crowd_line` по числу идущих.

## Строки `crowd_line` (по числу идущих)

| Идут | Строка |
|---|---|
| 0 | Лёд пока пустой |
| 1 | Пока один. Одному можно, но вдвоём веселее |
| 2 | Двое — это уже не катание, а свидание |
| 3 | Трое — это уже компания |
| 4 | Четверо — можно два на два |
| 5 | Пятеро — готовая хоккейная пятёрка |
| 6 | Шестеро — пятёрка и вратарь |
| 7–9 | Семеро / Восьмеро / Девятеро — каток, считай, ваш |
| 10+ | {N} человек — это уже не компания, а выезд |

Закрытые состояния: сеанс сняли; сбор снят (организатор); после сеанса при 2+ идущих — «Покатались», иначе «Сеанс прошёл».

## Создание

`POST /api/public/ice-companies`

Заголовок `X-Telegram-Init-Data`.

```json
{
  "session_id": 123,
  "name": "Пятничный лёд",
  "surface": "miniapp"
}
```

`name` — название команды на карточке. Имя организатора в «Иду» — из `user` в initData.

`201` — публичное тело с `going_count`, `crowd_line`, `card_text`, без порога и `needs_reconfirm`.

## Чтение

`GET /api/public/ice-companies/{public_code}`

## Ответ

`POST /api/public/ice-companies/{public_code}/responses` — идемпотентно по паре компания + участник. Ответ помечает карточку `card_dirty`.

## Остальные действия

| Метод | Путь | Кто |
|---|---|---|
| POST | `/api/public/ice-companies/{code}/cancel` | организатор |
| DELETE | `/api/public/ice-companies/{code}/me` | initData или токен |
| POST | `/api/public/ice-companies/{code}/telegram-prepare` | initData |
| GET | `/k/{code}` | страница, `noindex` |
| GET | `/k/{code}/og.png` | PNG 1080×1080 |
| GET | `/k/{code}/event.ics` | календарь |

Кнопка в мини-аппе: `startapp=company_{session_id}` → `/webapp/ice-company?s=`.

Планировщик `tick`: синхронизация сеанса → `expired` → правка грязных карточек → purge.
