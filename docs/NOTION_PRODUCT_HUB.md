# Trainer CRM — продуктовый хаб (для Notion)

Этот файл — **готовая структура** для страницы или базы в Notion: скопируйте разделы вручную или импортируйте Markdown (Notion → Import → Markdown).  
**Источник правды по коду** остаётся репозиторий (`specs/`, `docs/`); здесь — позиционирование и быстрые ссылки.

## Позиционирование

| Поле | Содержание |
|------|------------|
| **Вертикаль** | Всё вокруг **коньков**: фигурное катание, хоккей, ОФП для льда и смежные форматы. |
| **Цель** | Стать **ведущим** продуктом в сегменте «CRM + Telegram + мини-приложение» для тренеров и клиентов в этом контексте. |
| **Продукт сейчас** | **Trainer CRM Belarus** — два Telegram-бота (клиент / тренер), Mini App, API (FastAPI), PostgreSQL, уведомления, абонементы, заявки, расписание. |

## Чеклист для страницы в Notion (заполнить вручную)

- [ ] **ICP** — кто идеальный тренер и идеальный клиент (1 абзац каждый).
- [ ] **Клин** — одна фраза, зачем продукт существует.
- [ ] **Словарь** — термины (бронь, слот, абонемент, заявка, отклик) в вашей терминологии для маркетинга.
- [ ] **Метрики** — что меряем в первую очередь (активации, брони, retention).
- [ ] **Обещание** — что пользователь получает после онбординга (без технического жаргона).
