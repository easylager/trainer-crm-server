# Как работать с контекстом в этом репозитории

Четыре хранилища, у каждого одна роль. Смешивать их — то, из-за чего `.ai/` однажды
превратилась в кашу. Проверка при любом сомнении «куда это положить» — в таблице ниже.

| Где | Отвечает на вопрос | Как читается | Тест на принадлежность |
|---|---|---|---|
| `.ai/` | Где сейчас стоит работа | Целиком, каждую сессию | Изменится ли это на следующей неделе? Да → сюда |
| `docs/` | Что верно про продукт | Выборочно, по `docs/README.md` | Будет ли текст актуален через полгода? Да → сюда |
| `data/` | На каких данных работает код | Только кодом, не глазами | Ломается ли `src/` без этого файла? Да → сюда |
| `design/` | Как это выглядит | Выборочно | Это макет, прототип или визуальная система? Да → сюда |

Личное (резюме, cover letters, LinkedIn, PulseBridge) в репозитории **не хранится** —
оно в `~/Projects/personal-career/`.

## `.ai/` — состояние работы

```
.ai/                      симлинк → ~/Projects/.trainer-crm-state
├── project.md            дашборд на один экран: цель, стадия, что дальше
├── decisions.md          карточки PDEC-NNN — решения уровня проекта
├── tasks/
│   ├── INDEX.md          генерируется скриптом, руками не правится
│   └── TASK-NNN.md       живые задачи
└── archive/tasks/        закрытое и устаревшее, вне горячего чтения
```

`.ai/` **вне git и общая для всех worktree**. Так и задумано: состояние — не код, у него
не должно быть десяти версий по ветками. Раньше было наоборот, и десять worktree
разошлись между собой.

### Правила

1. **В `.ai/` только состояние.** Долгоживущий текст — в `docs/`. Если документ будет
   актуален через полгода, ему здесь не место.
2. **`.ai/` не растёт.** Устаревшее перезаписывается, а не дописывается рядом с заменой.
   Если раздел восстанавливается из файла задачи одним чтением — его тут быть не должно.
3. **ID выдаётся один раз и навсегда.** Файл называется строго `TASK-NNN.md`, без слага;
   человекочитаемое имя живёт в поле `title`. Номер = максимальный существующий + 1,
   никогда не переиспользуется. Именно смешение двух схем именования однажды дало
   тринадцать коллизий, когда `TASK-011` означал две разные задачи.
4. **Закрыл — увёз в архив.** `tasks/` содержит только живую работу.

### Допустимые значения

Только эти, иначе автоматика по статусам не работает:

- `status`: `READY` · `EXECUTING` · `VERIFYING` · `BLOCKED` · `RECOVERABLE` · `REPLAN_REQUIRED` · `COMPLETE`
- `phase`: `new` · `clarify` · `design` · `creative-explore` · `plan` · `estimate` · `implement` · `verify` · `design-review` · `review`

Проверить и пересобрать индекс:

```bash
python3 scripts/ai_index.py
```

Скрипт печатает список задач с недопустимыми значениями — если он молчит, всё чисто.

### Новый worktree

Состояние подключается симлинком, а не копией:

```bash
cd <новый-worktree> && rm -rf .ai && ln -s "$HOME/Projects/.trainer-crm-state" .ai
```

Девять существующих worktree ещё держат свои старые копии `.ai/` под git. Переводить
их стоит по одному, когда ветка домержена, — иначе git увидит массовое удаление
файлов в незавершённой работе.

## `docs/` — знания о продукте

Вход только через [`docs/README.md`](docs/README.md): одна строка на документ. Дерево
целиком не читать. Нет строки в индексе — документа не существует. Правила и раскладка
по папкам — там же.

## `data/` — данные, от которых зависит код

Реестры парсеров, фикстуры катков, калибровочные манифесты, прод-выгрузки CSV. На эти
пути ссылаются `src/ingestion/*`, `scripts/` и тесты, поэтому они стабильны и лежат в
git. Это не документация: читать их глазами не нужно, а перемещать — только вместе с
правкой путей в коде.

## Порядок работы

Рабочий процесс задаёт плагин `ai-toolkit-max`; здесь только то, что специфично для
репозитория.

1. `/project` — посмотреть, где стоим и что дальше. Это навигатор: он показывает
   следующий шаг, но никогда не делает его сам.
2. Задача берётся из `.ai/tasks/`, а не придумывается по ходу.
3. Перед действием файл задачи перечитывается с диска: память чата состоянием не является.
4. Решение с реальным компромиссом — карточка `PDEC-NNN` в `decisions.md`. Мелочь без
   альтернатив карточки не заслуживает.
