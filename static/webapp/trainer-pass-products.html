Абонемент

Welcome-ссылка

Клиент перейдёт по вашей ссылке и сразу увидит вашу карточку с уже выбранным абонементом — ему останется только подтвердить запись.

Подробнее

Если клиент уже занимается у вас вне системы, просто создайте для него абонемент нужного номинала, скопируйте персональную ссылку и отправьте её клиенту.

Когда клиент откроет ссылку:

  • увидит ваш профиль
  • получит уже привязанный абонемент
  • сможет записываться сам без лишних сообщений
  • занятия будут списываться автоматически после каждой записи

Это простой способ перевести клиента в систему без лишних объяснений и ручного контроля.
