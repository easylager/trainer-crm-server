# «Кто кого»: вечер лиги и своя лига в один тап

Утверждённые макеты (владелец, 2026-11-18). Живой холст: https://claude.ai/artifact/MFWbNR74WouE4a34A6aaRL

**v2 вечера (2026-11-19)** — холст https://claude.ai/artifact/2cxHY22go7XDNE6FLq2VWf, заменяет `League.dc.html` в части вечера: итог вечера (звезда и кепка), жесты иконками справа, след жеста на аватаре (стуки ×N, скамейка «2:00»), жест = смысл (`kind`) + облик (`skin`). Имена в итоге — меткой и крупно, без склонения.
Файлы — исходники артбордов холста (`.dc.html`): разметка с инлайн-стилями, данные — в `renderVals()`.
Цвета и шрифты те же, что в `static/webapp/kto-kogo.css` (`--kk-*`).

| Файл | Экран |
|---|---|
| `Main.dc.html` | Вечерняя сводка в боте: единственное уведомление, строка про кепку дня |
| `League.dc.html` | Тап по лиге → вкладка «Вечер» (переключатель Вечер · Месяц · Вся лига) |
| `Table.dc.html` | Та же лига, вкладка месяца: пьедестал и таблица (импортирует `League` с `tab="month"`) |
| `Rules.dc.html` | Шторка «Как считаются очки?», раздел «Кепка» |
| `Cover.dc.html` | Обложка «Лига друзей», 1280×720, фото еженедельного сообщения (неделя 1) |
| `Promo.dc.html` | Еженедельное сообщение игрокам без лиги |
| `Ready.dc.html` | По кнопке «Собрать лигу»: своя лига, «На что играем», «Позвать друзей» |
