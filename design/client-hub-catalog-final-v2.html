Рынок катания — один ансамбль

Пять категорий в одной ленте со счётчиками. Тип места читается цветом и значком: лёд — тил, тренер — тёмный тил, магазин — фиолет, сервис — графит. Одна система карточек — каждый тип отвечает на свой главный вопрос.

Пустого не существует

Чип, блок и карточка рендерятся только при данных: ноль школ — нет чипа школ, ноль категорий — нет ленты. Нет фото — нет фото-блока, вместо него иконка типа на плашке. Пустой результат фильтра — честный экран со сбросом.

Подборки только из данных

Шесть пресетов поверх того, что уже есть в системе: окно вечера, крытые, открытые, бесплатно, заточка, магазины. Каждый ведёт в каталог с применённым фильтром и рендерится только при счётчике больше нуля.

Изолированность без каши

Каждый тип и каждый экран живёт сам по себе: пустой город, пустая категория, карта, фильтры. Вместе — одно полотно, по отдельности — рабочий продукт.

Стиль не переделываем

Те же токены theme.css, та же сетка карточек и тени, что в тренерском приложении и B2B. Новое — только 4 токена типов мест, продолжение существующей палитры, а не её слом.

Светлый холст — везде

Мрачные тёмные плитки в светлом хабе — чуждо, как белое пятно карты в тёмной теме. Секции хаба — светлые, с иконкой типа на цветной плашке. Тёмное — только в экспортных картинках шеринга.

Что было не так

диагноз по твоему описанию, конституции и заметкам специалиста
«Подборки» и «свежее» — контент, который некому производить; через неделю пусто
Подборки — живые фильтры со счётчиками; «свежее» убрано, вместо него «сегодня на льду» из расписаний
Каталог = катки, остальной рынок спрятан или обещан — клиент не видит целое
Лента категорий со счётчиками: тренеры, школы, катки, магазины, сервис — рынок виден целиком, ноль не скрыт
Два блока «Сегодня на льду» (тизер сверху + блок внизу) — один смысл дважды, каша
Единый блок «На льду сейчас»: герой ближайшего сеанса + две строки расписания + «весь лёд»
«Места и тренеры» и «Подборки» — две навигации об одном рынке, у второй мелкий шрифт
«Куда катимся» — одна сетка: катки, тренеры, магазины, сервис со счётчиками и строкой ценности
«Рады вас видеть» — пустое приветствие, ничего не сообщает о дне и городе
«Вечер, Максим» + погода и живой счётчик дня: первая строка уже отвечает на вопрос
Тёмные плитки «Подборок» в светлом хабе — мрачно и чуждо, как чужая вставка
Светлые плитки «Куда катимся»: иконка типа на цветной плашке, счётчик, строка ценности. Тёмное — только в экспортных картинках
Чипы-нули («Школы · 0») и пустые блоки — обещание без наполнения
Чип рендерится только при данных; пустой результат фильтра — честный экран со сбросом
Место без фото — серый плейсхолдер, который выдаёт пустоту
Бесфотошный вариант карточки: иконка типа на плашке. Нет фото — нет фото-блока
Разные типы мест — разная подача, каша из карточек
Одна система: тип — цветом и значком, карточка каждого типа отвечает на свой главный вопрос
Хаб один на всех: у новичка пусто, у своего клиента — ссылки вместо данных
Хаб собирается из данных: у гостя — витрина города, у клиента — запись, тренер, абонемент, сертификат, серия
Карта — окошко на 25% экрана, пины без смысла
Карта — экран: пины-пилюли со временем, цвет пина — тип места, легенда, шторка-карусель, копирайт на месте
Шеринг спрятан, без тона и превью
Первый класс: тон «позвать с собой», выбор сеанса, подписанные каналы, тёмное превью с абсолютными датами

Данные и имена

Названия мест — примеры данных. Товарные знаки мессенджеров — только как кнопки-каналы шеринга, стандартное использование.

Самокритика v6 → v7:
  • Хаб пересобран как история, а не список блоков. Гость на входе получает один ответ за раз: «На льду сейчас» (герой ближайшего сеанса + две строки расписания — раньше это были два разнесённых блока с одним смыслом) → поиск → «Куда катимся» (рынок одной сеткой: катки, тренеры, магазины, сервис — раньше две навигации: «Места и тренеры» + «Подборки» мелким шрифтом) → каток недели.
  • Первая строка несёт ценность. «Рады вас видеть» заменено на «Вечер, Максим» + «−3° · лёд держит» + живой счётчик дня. Приветствие отвечает на вопрос, а не заполняет место.
  • У своего клиента своё сверху, рынок — всегда под рукой. Запись, тренер, абонемент, сертификат, серия — первыми; «Куда катимся» — ниже. Один и тот же блок, одна ментальная модель.
  • Карта для реализации: hubIceZone + hubIceToday → один блок «На льду сейчас»; hubDiscovery + hubCollections → одна сетка «Куда катимся»; hubGreeting → «Вечер, имя» + чипы. Существующие персональные блоки (запись, тренер, абонемент, upcoming, streak, saved) — только порядок, без переписывания.
  • Что по-прежнему не делаю: тёмную тему приложения, выдуманные данные, «скоро» без фактов, контент-блоки, которые некому вести.
